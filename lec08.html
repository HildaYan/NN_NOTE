徑向基底函數網路 RBF

Radial Basis Function Networks
← 回目錄← 上一講下一講 →📖 術語表
版面
🌱 先用一句白話理解 MLP 的神經元是「一條直線」,RBF 的神經元是「一個以某點為中心的圓/鐘形」。RBF 的每個隱藏神經元回答的問題是:「輸入離我的中心有多近?」越近輸出越接近 1,越遠越接近 0。最後輸出層把這些「相似度」加權相加。訓練分兩步:先自己分群找中心(不用答案),再用答案調輸出權重。

RBF 是什麼?
Q1RBF 與 MLP 結構上最大差異?
RBF 通常只有一層隱藏層,且啟動函數為高斯函數。
Q2RBF 誰提出?何時?
Broomhead & Lowe,1988。
  • Radial Basis Function 網路,簡稱 RBF。
  • 與 MLP 不同:典型結構只有一層隱藏層,且隱藏層啟動函數為高斯函數。
  • 屬多層前饋架構,監督式訓練。(1988 Broomhead & Lowe)
本段重點RBF 只有一個隱藏層,用高斯函數,屬多層前饋、監督式。
兩階段訓練必考
Q1RBF 的兩階段訓練分別是什麼?
Stage 1:自組織(非監督)調隱藏層;Stage 2:廣義 Delta 規則(監督)調輸出層。
Q2為什麼 Stage 1 可以不用答案?
只需在輸入空間找資料集中位置,與類別標籤無關。
階段對象方法
Stage 1隱藏層(中間層)自組織學習(非監督):決定高斯函數的中心 c 與寬度 σ
Stage 2輸出層廣義 Delta 規則(監督):同 MLP 最後一層
本段重點Stage 1 用非監督調隱藏層;Stage 2 用 Delta 規則調輸出層。
高斯啟動函數
Q1c 與 σ² 的意義?
c=高斯中心;σ²=變異數,越大曲線越胖。
Q2σ² 變大時高斯曲線如何變化?
變胖,涵蓋範圍更廣。
g(u) = exp( −(u − c)² / (2σ²) )
u=電位,c=中心,σ=標準差(σ²=變異數,決定鐘形的寬窄)。σ² 越大越胖(涵蓋範圍大)。
一般 c 直接對應隱藏層的權重。
本段重點高斯 g(u)=exp(−(u−c)²/2σ²),c 為中心、σ 為寬度。
隱藏層輸出
Q1輸入剛好在中心時隱藏層輸出多少?
1。
Q2輸入離所有中心都很遠時?
所有隱藏神經元輸出≈0。
第 j 個隱藏神經元(n=輸入向量元素數,n₁=隱藏神經元數):
Yj(1) = exp( − ‖ x − cj ‖² / (2σj²) ) , j = 1…n₁
‖x − cj‖ = 輸入與中心的距離。x 越靠近中心輸出越接近 1。
本段重點隱藏輸出 Y=exp(−‖x−c‖²/2σ²):離中心愈近愈接近 1。
MLP vs RBF 邊界必考
Q1MLP 與 RBF 單一神經元的邊界形狀?
MLP:超平面(二維為線);RBF:超球面(二維為圓)。
Q2用 RBF 圈住一個圓形群集需要幾個隱藏神經元?
1 個(單一接受域即可)。
MLPRBF
單一神經元的邊界超平面(直線)超球面(圓)
二維線圓
三維平面球
一個神經元能做到切一刀圈出同一類的所有點(單一接受域)
本段重點單一神經元邊界:MLP 是超平面,RBF 是超球面。
Stage 1:怎麼找中心?k-means
Q1k-means 兩個核心步驟?
Group(依最近中心分組)與 Update(新中心=組內平均)。
Q2k-means 的 k 對應什麼?
隱藏神經元個數。
用 k-means 分群(非監督)決定高斯中心。步驟:
  1. 設定群數 k(= 隱藏神經元數 n₁)。
  2. 初始中心:令 W = 選出的樣本 x。
  3. 分組 Group:每個樣本歸到離它最近的中心。
  4. 更新 Update:每組的新中心 = 該組樣本的平均。
  5. 重複 3–4 直到中心不再變動。
最終的中心 = 隱藏層權重。
本段重點Stage 1 用 k-means:分組→取平均更新中心,重複到穩定。
Stage 1:怎麼找變異數?
Q1其他可用來分群的方法?
最大似然準則(Nowlan 1989)、遞迴最小均方(Chen 1995)。
Q2k-means 屬於監督還是非監督?
非監督式。
依每個中心周圍接受域(receptive domain)的涵蓋半徑計算 σ²:涵蓋範圍大(樣本分散)→ σ² 大。 其他分群法:最大似然準則(Nowlan 1989)、遞迴最小均方(Chen 1995)。
本段重點σ² 由接受域的涵蓋半徑決定;另可用最大似然或遞迴最小均方。
Stage 2:輸出層
Q1RBF 輸出層啟動函數?
線性函數。
Q2Stage 2 的更新方式?
與 MLP 輸出層相同的廣義 Delta 規則。
輸出層是線性函數:
uk = Σⱼ Wkj(2) · Yj(1) − θk , Yk(2) = uk
把隱藏層輸出當輸入,用與 MLP 輸出層相同的 Delta 規則更新 W(2)、θ。
本段重點輸出層為線性:u=ΣWY−θ,以 Delta 規則更新。
運作流程
Q1RBF 運作階段的三步?
算隱藏層輸出 → 算輸出層電位 → 輸出層輸出。
Q2RBF 輸出層的啟動函數是線性還是非線性?
線性。
輸入 x → 算隱藏層輸出(高斯)→ 算輸出層電位(加權和)→ 線性輸出。
本段重點運作:輸入→隱藏層高斯輸出→輸出層加權和→輸出。
RBF 函數逼近
Q1範例中三個高斯的參數?
(c=−3, σ²=5.0)、(c=0, σ²=0.7)、(c=5.5, σ²=0.5);輸出權重 −0.15、0.30、0.70。
Q2與 MLP 範例的對應關係?
MLP:λ 縮放、θ 位置;RBF:權重縮放,c 與 σ² 決定位置與寬度。
f(x) ≈ Σⱼ W1j⁽²⁾ · exp( −(x − cj)² / 2σj² )
範例:3 個高斯 — (c=−3, σ²=5.0)、(c=0, σ²=0.7)、(c=5.5, σ²=0.5);輸出權重 W=−0.15、0.30、0.70。
W = 縮放(高度),c = 位置,σ² = 大小(寬度)。對照 MLP:λ=縮放,θ=位置。
本段重點函數逼近=多個高斯疊加:權重控高度、c 控位置、σ² 控寬度。
RBF 沒有偏權值?
Q1RBF 隱藏層為什麼不需要 bias?
高斯函數的中心 c 已決定其位置。
Q2隱藏神經元數如何決定?
用交叉驗證選拓樸。
RBF 隱藏層不含 bias,因為高斯本身已用「中心」決定位置。至於要幾個隱藏神經元才夠擬合 → 用交叉驗證選拓樸。
本段重點RBF 隱藏層不含 bias,因為中心已決定位置。
RBF 分類
Q1分類範例中神經元 A、B 的差別?
A 的變異數比 B 大(涵蓋範圍較廣)。
Q22 個與 8 個隱藏神經元的差別?
8 個的超球面邊界更貼合資料。
例:神經元 A、B 的中心由 k-means 求得,A 的變異數比 B 大。輸出層做線性組合(正/負權重),再重新映射(re-map)成分類結果。
邊界:MLP 是線→超平面;RBF 是圓→球→超球面邊界。例:2 個 vs 8 個隱藏神經元,後者邊界更貼合。
本段重點分類:k-means 求 A、B 的中心,輸出層線性組合再映射成類別。

🎓 詳細教學(零基礎版)

1. 用「手電筒光圈」理解高斯神經元

每個隱藏神經元像一支手電筒照在地面上:c=手電筒的位置,σ=光圈大小。你站的位置(輸入 x)離手電筒越近,亮度越高(輸出→1),離得越遠越暗(輸出→0)。

2. 兩種網路怎麼「圍」住一群點?

MLPRBF
比喻用很多把直尺切出多邊形用很多個圓形印章蓋住區域
圍一個圓形群集需 ≥3 條線(三角形)才能圍出封閉區域1 個隱藏神經元就夠
擅長大範圍的趨勢、遠處外插局部的、集中的群集
局部性RBF 是「局部反應」:離所有中心都很遠的輸入,所有隱藏神經元都輸出≈0,網路不會亂猜。這與 MLP 的「全域反應」不同。

3. k-means 一回合手算

一維資料:1, 2, 3, 10, 11, 12。想分 2 群(k=2),初始中心 c₁=1、c₂=10。

  1. 分組:1 離 c₁(1)最近;2→c₁(距離1 vs 8);3→c₁(2 vs 7);10→c₂;11→c₂;12→c₂。
  2. 更新中心:c₁ = (1+2+3)/3 = 2;c₂ = (10+11+12)/3 = 11。
  3. 再分組:結果不變 → 中心不再移動 → 收斂。
  4. 估變異數(常見做法:群內樣本到中心的平均平方距離):群1 = ((1−2)²+0+(3−2)²)/3 ≈ 0.67;群2 同理 ≈ 0.67。
兩個高斯就完成c=2, σ²≈0.67 與 c=11, σ²≈0.67 → 隱藏層準備完成。再用 Delta 規則學輸出層權重。

4. Stage 2:為什麼這麼簡單?

隱藏層固定後,輸出只是「隱藏層輸出的線性組合」—— 這和 ADALINE 完全相同:輸入是 Y⁽¹⁾,輸出是線性,誤差是 d − Y⁽²⁾。所以更新式為 ΔW⁽²⁾ = η(d − Y⁽²⁾) Y⁽¹⁾(線性輸出 g′=1)。這也是為什麼 RBF 通常比 MLP 訓練快:只有一層需要梯度下降,而且誤差曲面沒有局部最小值問題(對輸出權重而言是凸的)。

5. 逼近曲線的直覺

用 3 個鐘形:(c=−3,胖,權重−0.15 → 小小的負向山丘)、(c=0,瘦,權重0.30)、(c=5.5,更瘦,權重0.70 → 高高的尖峰)。三個鐘形疊加(superposition,疊加原理)得到最終曲線。MLP 版本也是疊加,只是積木是 S 形而非鐘形。

7. 常見疑問

Q:隱藏神經元要幾個?沒有公式,講義建議用交叉驗證試。太少擬合不夠細,太多會過擬合,與第 7 講同樣的道理。k-means 的 k 就是它。
Q:Stage 1 為什麼可以不用答案?因為只是在輸入空間裡找「資料集中在哪些地方」,不需要知道它們屬於哪一類,所以是非監督。
Q:高斯 σ 與 σ² 要分清楚。講義寫 exp(−(u−c)²/2σ²) 中的 σ² 是變異數;σ 是標準差。範例裡標出的「σ²=5.0」是變異數。
