學習向量量化(LVQ)

Learning Vector Quantization

🌱 先用一句白話理解 上一講的 SOM 沒有答案;這一講的 LVQ 是它的「有答案版」。每個神經元代表一個類別,新樣本進來,最近的神經元當贏家:如果它的類別猜對了,就往樣本靠近;猜錯了,就被推開。久了之後,每個類別的代表向量都站到自己地盤的中央,分界線就是它們之間的中垂線。

LVQ 是什麼?
Q1LVQ 屬於監督式還是非監督式?跟 SOM 的關係?
監督式學習;結構與訓練方式很像 Kohonen 的 SOM,可視為 SOM 的監督式版本。
Q2LVQ 通常用在什麼問題?
樣式分類(pattern classification)。
  • Learning Vector Quantization(LVQ)= 有監督的人工神經網路。
  • 與 Kohonen SOM 相似(都是競爭式)。
  • 通常用於樣式分類問題。
本段重點LVQ=監督式的競爭網路,長得像 SOM,用來做分類。
向量量化 VQVector Quantization
Q1向量量化在做什麼?什麼叫量化向量(碼向量)?
替每一類指定一個獨一無二的向量,稱為量化向量(quantizing vector)或碼向量(code vector),代表該類樣本的樣式。
Q2量化向量放在哪裡?
放在樣本最密集處;與該類所有樣本的距離總和最小。若該類呈常態分佈,它會接近樣本平均值。
  • VQ:替每個類別指定一個代表向量(量化向量 / 碼向量 code vector)。
  • 該向量與類內所有樣本的距離總和最小,位於樣本最密集處。
  • 若類內樣本為常態分佈,量化向量趨近平均值。
本段重點每類一個代表向量,放在樣本最密處(常態時=平均)。
分類與邊界Hyperplane / Voronoi
Q1新樣本怎麼決定屬於哪一類?
離哪個量化向量最近就屬於那一類。
Q2類別邊界怎麼來?
兩個量化向量連線的中垂超平面(中點且垂直於連線);所有邊界合起來就是 Voronoi 圖。
Q3Voronoi 圖的兩種建法與複雜度?
增量法(一次加一個類中心)O(N²);分治法(divide-and-conquer)O(N log N)。
  • 新樣本屬於最近的量化向量所代表的類。
  • 邊界 = 任兩量化向量的中點,為與連線垂直的超平面(hyperplane)。
  • 這個應用就是 Voronoi 圖(類中心地圖)。
  • 建法:增量法 O(N²)(一次加一個類);分治法 O(N log N)(找外公切線 → 沿中垂線追蹤 → 碰到邊界就換類中心,直到最後一條中垂線)。
本段重點最近的量化向量定類別;邊界是中垂超平面,合成 Voronoi 圖。
VQ 與分群、壓縮VQ vs Clustering
Q1VQ 和分群(clustering)有何差別?
VQ 包含分群的特性(把有共同特徵的樣本歸類),還會把整個輸入空間轉成離散的輸出空間,因此有明顯的降維效果。
Q2VQ 在資料壓縮怎麼用?
用歐氏距離找碼簿(codebook)中失真最小的碼字,只傳碼字的索引;可省儲存空間與通訊頻寬。
  • 分群:把有共同特徵的樣本分到各類。
  • VQ:含分群的功能 + 把整個輸入空間變成離散輸出空間 → 降維。
  • 圖示:輸入向量(x)、碼字(紅圈)、Voronoi 區域(邊界線)。
  • 應用:資料壓縮——輸入以碼字索引輸出;碼字以歐氏距離失真最低者選出;用於電腦儲存、通訊通道。
本段重點VQ=分群+離散化降維;壓縮時只傳最近碼字的索引。
LVQ 網路Kohonen 1995
Q1LVQ 是誰、何時提出?
Teuvo Kohonen(講義寫 1995),被視為 SOM 的監督式版本。
Q2LVQ 的神經元權重代表什麼?
代表對應的量化向量。
Q3LVQ 有沒有側向連接?跟 SOM 差在哪?
沒有側向連接,鄰居不影響贏家調整;只調整贏家(LVQ-1)或贏家+副贏家(LVQ-2)。
  • Kohonen(1995)提出,是 SOM 的監督式版本;訓練用競爭法,與 SOM 類似。
  • 神經元權重向量 = 對應的量化向量。
  • 沒有側向連接 → 鄰居不影響贏家的調整(不像 SOM 有鄰域)。
  • 兩種訓練演算法:LVQ-1 只調整贏家;LVQ-2 調整贏家與副贏家(vice-winner)。
⚠ 講義寫 LVQ 為 Kohonen(1995),但 LVQ-2.1 卻標「Kohonen 1990」,年份看起來倒置;以老師口頭說明為準。
本段重點LVQ:無鄰域、有答案;LVQ-1 調贏家,LVQ-2 調贏家+副贏家。
LVQ-1:選贏家Step 1
Q1LVQ-1 兩個主要步驟?
①取得贏家神經元 ②決定贏家權重的調整規則。
Q2怎麼找贏家?
算輸入與每個神經元權重的歐氏距離,最小者為贏家。

  • x⁽ᵏ⁾=第 k 個輸入樣本;w⁽ʲ⁾=第 j 個神經元權重;n₁=神經元數;n=輸入維度。
  • 與 SOM 一樣用歐氏距離(norm-2)決定贏家。
本段重點贏家=歐氏距離最小的神經元(與 SOM 相同)。
LVQ-1:調整權重Step 2
Q1贏家的類別與期望類別相同時怎麼調?
靠近:w⁽ʲ⁾ ← w⁽ʲ⁾ + η(x − w⁽ʲ⁾)。
Q2不相同時怎麼調?
遠離:w⁽ʲ⁾ ← w⁽ʲ⁾ − η(x − w⁽ʲ⁾)。
Q3跟 SOM 的規則 1 差在哪?
多了「對錯判斷」:SOM 贏家永遠靠近輸入;LVQ-1 判對才靠近、判錯就推開。
若 x(k) ∈ C(j)(贏家類別 = 期望類別):w(j) ← w(j) + η·( x(k) − w(j) ) 〔靠近 move close〕
否則(x(k) ∉ C(j)):w(j) ← w(j) − η·( x(k) − w(j) ) 〔遠離 move away〕
  • C⁽ʲ⁾ = 神經元 j 所代表的類別。
  • 贏對了 → 拉近;贏錯了 → 推開,這就是「有監督」的來源。
  • 圖示(兩類 {C₁, C₂}):輸入屬於贏家類別時往輸入移動;不屬於時往反方向移動。
本段重點贏家類別對(同期望)→ 靠近;錯 → 遠離。
LVQ-1 演算法流程Training / Operation
Q1LVQ-1 訓練的步驟?
取樣本 → 標上期望類別 → 以各類樣本值初始化權重 → 正規化 → 設 η → epoch←0 → 重複:對每個樣本算距離、取贏家、依規則調整、再正規化;epoch+1,直到權重無明顯變化。
Q2運作階段怎麼分類?
樣本先正規化 → 載入訓練好的權重 → 算歐氏距離 → 取贏家 → 輸出贏家所代表的類別。
  1. 取得訓練樣本 {x⁽ᵏ⁾}。
  2. 為每個樣本指定期望類別 {C⁽ʲ⁾}。
  3. 用該類的樣本值初始化各權重向量 {w⁽ʲ⁾}。
  4. 正規化樣本與權重。
  5. 指定學習率 η。
  6. epoch ← 0。
  7. 重複:對所有樣本 ①算歐氏距離 ②贏家 = argminⱼ‖x⁽ᵏ⁾−w⁽ʲ⁾‖ ③依對錯拉近/推開贏家 ④正規化被調整的權重;epoch ← epoch+1;直到無明顯變化。

運作階段:①呈現待分類樣本並正規化 ②載入訓練好的權重 ③算距離、宣告贏家 ④樣本歸為贏家所代表的類 ⑤輸出類別。

本段重點訓練:找贏家→對則拉、錯則推;運作:最近神經元的類就是答案。
LVQ-2Winner + Vice-winner
Q1LVQ-2 比 LVQ-1 多調整了誰?
多調整副贏家(vice-winner,第二近的神經元)。
Q2贏家類別正確、副贏家類別錯誤時怎麼調?
贏家靠近(w⁽ʲ⁾+η(x−w⁽ʲ⁾)),副贏家遠離(w⁽ᵐ⁾−η(x−w⁽ᵐ⁾))。
Q3贏家錯、副贏家對時呢?
贏家遠離、副贏家靠近。
若 x∈C(j) 且 x∉C(m)(贏家對、副贏家錯):
　w(j) ← w(j) + η(x−w(j)) 〔靠近〕,w(m) ← w(m) − η(x−w(m)) 〔遠離〕
若 x∉C(j) 且 x∈C(m)(贏家錯、副贏家對):
　w(j) ← w(j) − η(x−w(j)) 〔遠離〕,w(m) ← w(m) + η(x−w(m)) 〔靠近〕
  • w⁽ʲ⁾=贏家,w⁽ᵐ⁾=副贏家;C⁽ʲ⁾、C⁽ᵐ⁾ 為它們各自代表的類。
  • 流程同 LVQ-1,只是步驟 7.1.2 要同時取得贏家與副贏家,7.1.3 依上面兩條規則調整兩者。
  • 其他情況(兩者都對或都錯)講義沒有列出調整規則。
本段重點LVQ-2:贏家與副贏家一對一錯時,對的拉近、錯的推開。
LVQ-2.1 與視窗Window λ
Q1LVQ-2.1 與 LVQ-2 的差別?
只有當樣本落在贏家與副贏家邊界附近的隸屬視窗(window)內才調整。
Q2視窗條件是什麼?λ 多大?
min(d_j/d_m, d_m/d_j) > (1−λ)/(1+λ),λ ∈ [0.2, 0.3]。
Q3LVQ-2.1 的目的?
把兩個向量移到類別邊界附近,以降低分類錯誤(貝氏邊界)。
min( dj/dm , dm/dj ) > (1 − λ)/(1 + λ) , λ ∈ [0.2, 0.3]
  • LVQ-2.1(Kohonen 1990)與 LVQ-2 類似,但只在樣本位於 w⁽ʲ⁾、w⁽ᵐ⁾ 邊界周圍的視窗內才調整。
  • d_j、d_m = 樣本到贏家、副贏家的距離;λ = 定義視窗寬度的係數。
  • 意義:樣本到兩者距離差不多(靠近邊界)時才更新 → 把 w⁽ʲ⁾、w⁽ᵐ⁾ 移到分隔兩類的邊界附近。
  • λ=0.25 → 門檻 (1−0.25)/(1+0.25)=0.6。
本段重點LVQ-2.1:只有樣本在邊界視窗內才更新,把向量推到邊界。

🎓 詳細教學(零基礎版)

1. 先搞懂 VQ:每一類派一個「代表」

想像全班同學要分成幾個小組,每組選一位代表站在小組最擠的地方(這就是量化向量/碼向量)。新同學來了,看離哪位代表最近就加入那一組。兩位代表之間的「分界線」,就是它們連線的中垂線(高維就是中垂超平面),所有分界線畫出來就是 Voronoi 圖。

VQ 跟分群很像,但它還把整個輸入空間變成「有限個代表」——這就是離散化、降維,也能拿來壓縮資料:只傳「最近代表的編號」,不傳完整向量。

2. 從 SOM 到 LVQ:多了「答案」

SOM(第 10 講)LVQ(第 11 講)
有沒有答案沒有(非監督)有(每個樣本有期望類別)
鄰域/側向連接有,鄰居一起更新沒有
贏家怎麼更新永遠靠近輸入類別對 → 靠近;類別錯 → 遠離
用途降維、視覺化、分群樣式分類
找贏家都用歐氏距離最小

3. LVQ-1:贏對拉近、贏錯推開

每個神經元有一個權重向量 w 和一個類別標籤 C。輸入 x 進來,找最近的 w 當贏家:

  1. 贏家的類別 = x 的期望類別 → w ← w + η(x − w)(往 x 靠近)。
  2. 贏家的類別 ≠ x 的期望類別 → w ← w − η(x − w)(離 x 遠一點)。
  3. 更新後做正規化,重複到權重不再明顯變動。
手算:LVQ-1 兩種情況 神經元 1:w₁=(1,1),類別 A;神經元 2:w₂=(3,3),類別 B;η=0.5。
情況一:x=(2,1),期望 A。d₁²=1、d₂²=1+4=5 → w₁ 贏、類別相同 → w₁=(1,1)+0.5×(1,0)=(1.5, 1)(靠近)。
情況二:x=(2,2.5),期望 A。d₁²=1+2.25=3.25、d₂²=1+0.25=1.25 → w₂ 贏,但它是 B ≠ A → w₂=(3,3)−0.5×(−1,−0.5)=(3.5, 3.25)(被推遠)。

4. LVQ-2:連副贏家一起調

「副贏家」就是第二近的神經元。LVQ-1 贏錯時只把贏家推開,但真正該贏的類別沒得到幫助;LVQ-2 在贏家和副贏家一對一錯時兩個一起調:

情況贏家 w⁽ʲ⁾副贏家 w⁽ᵐ⁾
贏家對、副贏家錯靠近 +η(x−w)遠離 −η(x−w)
贏家錯、副贏家對遠離 −η(x−w)靠近 +η(x−w)

白話:對的人靠過去,錯的人退開,把兩個類別的「分界線」推到更合理的位置。

5. LVQ-2.1:只在邊界附近才調整

LVQ-2 對離邊界很遠的樣本也會調整,可能把向量越推越偏。LVQ-2.1 加了「視窗」:只有樣本離贏家與副贏家的距離差不多(= 靠近邊界)才更新。條件:

min( d_j/d_m , d_m/d_j ) > (1−λ)/(1+λ) , λ∈[0.2, 0.3]
手算:視窗判斷(λ=0.25 → 門檻 0.6) ① d_j=2、d_m=2.5:min(0.8, 1.25)=0.8 > 0.6 → 在視窗內,要更新。
② d_j=1、d_m=3:min(0.333, 3)=0.333 < 0.6 → 在視窗外(離邊界太遠),不更新。
d_j/d_m 越接近 1,代表樣本越靠近邊界。

6. 訓練後怎麼分類?(運作階段)

  1. 新樣本 x 先正規化。
  2. 載入訓練好的權重(不再更新)。
  3. 算 x 與每個神經元的歐氏距離,最近者為贏家。
  4. 輸出贏家所代表的類別。

7. 範例:LVQ-1 跟 K-means 的比較

講義 Example-1:12 個二維樣本、3 個神經元(神經元 1→class 1,神經元 2、3→class 2)、η=0.1、訓練 100 個 epoch。結果:LVQ-1 與 K-means 的中心很接近;不同處是 LVQ-1 知道每個樣本的類別,而 K-means 完全不用類別資訊。收斂曲線(權重變化總和)在約 20 個 epoch 後趨近 0,表示訓練穩定。

9. 常見疑問

Q:LVQ 與 SOM 最大的不同?LVQ 是監督式且沒有鄰域:要靠期望類別判斷「贏對還是贏錯」;SOM 非監督,贏家的鄰居也被更新。
Q:為什麼贏錯要「推開」?贏家的類別和樣本不同,代表這個代表向量跑到別類的地盤去了;往反方向移動,能讓它離該樣本遠一點,以後別再搶錯。
Q:LVQ-1、LVQ-2、LVQ-2.1 怎麼分?LVQ-1:只調贏家。LVQ-2:贏家+副贏家(一對一錯時)。LVQ-2.1:在 LVQ-2 基礎上再加「視窗」,只在邊界附近才調。
Q:LVQ 的神經元數怎麼決定?講義沒有明說;例題是每個類別至少給一個神經元(3 個神經元、2 類)。
