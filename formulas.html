公式白話手冊

看不懂公式?先翻譯,再抓骨架,最後手算一次

🌱 先說一件事 公式看不懂,通常不是數學不好,而是沒有「翻譯」。每一條公式其實就是一個中文句子,只是用符號寫得很濃縮。這份手冊的做法:每條公式都先翻成人話,再用最小的數字算一次,算過一次就不會怕了。

1. 記公式的「三步驟」

① 翻譯把每個符號換成中文,唸成一句話。例:w ← w + η(d−y)x =「新的權重 = 舊的權重 + 學習率 × (答案−我的輸出) × 輸入」。
② 抓骨架全課程的更新式都長一樣:新 = 舊 + η × 誤差 × 輸入。看到新公式先問:「誤差」在哪?「輸入」在哪?
③ 手算一次用 2~3 個小數字(像 0.5、1、2)代入算出答案。算過一次,公式就從「符號」變成「動作」。
記憶訣竅不要「背符號」,要背「這條公式在回答什麼問題」:例如 δ 回答「這個神經元該背多少責任?」;g′ 回答「啟動函數此刻坡度多陡?」;μ 回答「要冒險(像牛頓法)還是保守(像梯度下降)?」

3. 一張圖看出「主旋律」

新 = 舊 + η × 誤差 × 輸入
方法新=舊+η×誤差×輸入 的對應
感知器w ← w + η·(d−y)·x
ADALINEw ← w + η·(d−u)·x
MLP 輸出層W ← W + η·[(d−Y)g′(I)]·Y前層
MLP 隱藏層W ← W + η·[g′(I)Σδ後層W]·Y前層(或 x)
RBF 輸出層W ← W + η·(d−Y)·Y隱藏層
加動量再加上 α·(上次的變化量)

4. 公式卡片(逐條拆解)

每張卡:公式 → 白話 → 記憶法 → 手算 → 易錯。數字都已驗算。

第 1 講

神經元輸出

u = Σᵢ wᵢxᵢ − θ , y = g(u)
白話
每個輸入乘上自己的重要性,全部加起來,扣掉門檻,再丟進啟動函數。
記憶
「評審團投票」:信誰權重大;θ 是及格線。
手算
x=(1, 0.5)、w=(0.4, 0.8)、θ=0.3:u = 0.4×1 + 0.8×0.5 − 0.3 = 0.5;若 g 是 logistic,y = 1/(1+e−0.5) ≈ 0.6225。
易錯
減的是 θ,不是加;ReLU 對負的 u 輸出 0。
第 1、5 講

logistic 與它的導數

g(u)=1/(1+e−u) , g′(u)= g(u)·(1−g(u)) = Y(1−Y)
白話
sigmoid 的坡度,只要知道輸出 Y 就能算,不必再算指數。
記憶
「Y 乘 (1−Y)」:Y=0.5 時最大(0.25),Y 靠近 0 或 1 時趨近 0(=梯度消失)。
手算
Y=0.8 → g′ = 0.8×0.2 = 0.16。Y=0.5 → 0.25。
易錯
用的是「輸出 Y」,不是輸入 u。
第 3 講

感知器更新(誤差修正)

w(n+1) = w(n) + η·[d(n) − y(n)]·x(n)
白話
分對了(d=y)就不動;分錯了,把線往「讓這個點被分對」的方向推一點。
記憶
d−y 只有 0、+2、−2 三種:對=0,錯成 −1=+2,錯成 +1=−2。
手算
η=0.5,w=[0,1,−1],x=[−1,2,1],d=−1:u=0×(−1)+1×2+(−1)×1=1 → y=+1;d−y=−2;Δw=0.5×(−2)×x=[1,−2,−1];新 w=[1,−1,−2]。
易錯
x 第一項是 −1(代表閾值);別忘了乘 η。
第 3 講

收斂次數上限

n_max = β‖w₀‖² / α² , α = min w₀ᵀx , β = max ‖x‖²
白話
最多更新這麼多次就一定停:輸入越「大」(β)、解越「難分」(α 小),次數越多。
記憶
「下界 n²、上界 n」:n² 追上 n 的地方就是 n_max;不用背推導,背這個故事即可。
易錯
前提是線性可分;不可分時永遠不收斂。
第 4 講

ADALINE 的誤差與更新

E(w)=½Σ(d−u)² ; ∇E = −Σ(d−u)x ; w ← w + η(d−u)x
白話
把「每筆錯多少」平方後加總(誤差碗);沿碗的下坡走(梯度的反方向)。
記憶
梯度本身帶負號,「往下走」再取負 → 負負得正,所以更新式是「+」。
手算
η=0.1,w=[0.5,0.2,0.1],x=[−1,1,2],d=1:u=−0.5+0.2+0.2=−0.1;d−u=1.1;Δw=0.1×1.1×x=[−0.11,0.11,0.22];新 w=[0.39,0.31,0.32];新 u=0.56,誤差 0.44。
易錯
用 u(啟動前)不是 y;½ 是為了微分好看。
第 4 講

MSE 與停止條件

MSE = (1/p)Σ(d−u)² ; |MSE_now − MSE_prev| ≤ ε
白話
平均每筆錯多少;相鄰兩輪差不多就停。
手算
誤差 (1, −2):MSE = (1+4)/2 = 2.5。
第 5 講

MLP 前向

Ij(L) = Σᵢ Wji(L) Yi(L−1) , Yj(L) = g(Ij(L))
白話
每層都做一樣的事:前一層輸出加權相加(I),再過啟動函數(Y)。上一層的 Y 就是下一層的輸入。
記憶
W_ji = 「去 j、來 i」。
第 5 講

輸出層 δ 與權重更新

δⱼ = (dⱼ − Yⱼ)·g′(Iⱼ) , ΔWji = η·δⱼ·Yᵢ(前一層)
白話
誤差越大、啟動函數此刻越「有感」(g′ 大),責任 δ 越大;更新量再乘上「來源神經元的輸出」。
記憶
δ =「差多少」×「坡多陡」;ΔW = η × δ × 「從哪個神經元來」。
手算
d=1、Y=0.7(logistic):g′=0.7×0.3=0.21;δ=0.3×0.21=0.063;若 η=0.5、前層輸出 0.6:ΔW=0.5×0.063×0.6=0.0189。
易錯
g′ 要用「這個神經元」的 I 或 Y,不是別層的。
第 5 講

隱藏層 δ(倒傳)

δⱼ⁽ᴸ⁾ = g′(Iⱼ⁽ᴸ⁾) · Σₖ δₖ⁽ᴸ⁺¹⁾ · Wₖⱼ⁽ᴸ⁺¹⁾
白話
我(第 j 個隱藏神經元)的責任 = 我的坡度 ×「後面每個神經元的責任,按它對我的連線權重加權後加總」。
記憶
責任沿著連線倒著走;權重大的連線分到的責任多。
手算
g′(I)=0.25,後層 δ=0.1,連線權重 W=0.4(只有一條路):δ = 0.25×0.1×0.4 = 0.01。
易錯
用「更新前」的後層權重;先算完所有 δ 再統一更新。
第 5 講

鏈鎖律三連乘

∂E/∂W = (∂E/∂Y)(∂Y/∂I)(∂I/∂W) = [−(d−Y)] · [g′(I)] · [Y前層]
白話
權重影響誤差,要「經過」I 與 Y 兩站:誤差對輸出 × 輸出對輸入 × 輸入對權重。
記憶
像水管串接:每一段的「放大倍率」乘起來。更新取負梯度,所以 −(d−Y) 變成 +(d−Y)。
第 5 講

動量

W(t+1) = W(t) + ηδY + α·[W(t) − W(t−1)]
白話
除了這次算出的調整量,再帶一點「上次走的方向」。
記憶
滾下山的球:有慣性,越滾越快、抗小坑。
手算
η=0.2,δ=0.3,Y=0.5,α=0.8,上次變化 0.05:ηδY=0.03;α×0.05=0.04;總調整量 0.07。
第 5 講

Rprop(不用公式的公式)

白話
只看「這次的坡」和「上次的坡」方向同不同:同號 → 學習率乘以大於 1 的數(加速);反號 → 乘以小於 1 的數(跨過谷底了,減速)。
記憶
「同向加油、反向煞車」。好處:不怕梯度很小(飽和區)。
第 5 講

Levenberg–Marquardt

W ← W − (JᵀJ + μI)⁻¹ Jᵀ E
白話
用「誤差對每個權重的一階偏導」(J)去估計曲面彎度,一步跳到谷底附近;μI 是安全墊。
記憶
μ 小→大膽(像牛頓法);μ 大→保守(像梯度下降)。誤差變好就減小 μ,變差就增大 μ。J 的大小是「樣本數 p × 權重總數 M」。
易錯
不用背推導;會寫公式、會說 μ 的作用即可。
第 5 講

牛頓法

xₙ₊₁ = xₙ − f(xₙ)/f′(xₙ)
白話
用切線的交點當下一個猜測,一步步逼近根。
手算
求 √2(f=x²−2),x₀=1:f=−1,f′=2 → x₁=1−(−1)/2=1.5;x₁:f=0.25,f′=3 → x₂=1.5−0.25/3≈1.4167(真值 1.4142)。
第 6、7 講

建構題常用的數數公式

權重總數
Σ(前層節點數+1)×本層節點數。例 3-4-2:(3+1)×4+(4+1)×2 = 26。(+1 是閾值)
TDNN 樣本數
N − n_p。例 N=30、n_p=3 → 27;帶回饋輸入節點=n_p+n_c。
k 折
N=150、k=5:每次訓練 120、測試 30,共 5 次;留一法共 N 次。
輸出類別
m 個輸出最多 2^m 類;1-of-c 用 c 個輸出。
第 7 講

訊號縮放與還原

z = 2(x − x_min)/(x_max − x_min) − 1 ; x = x_min + (z+1)(x_max − x_min)/2
白話
先算 x 在範圍中的比例(0~1),乘 2 再減 1 變成 −1~1。
手算
x∈[0,200],x=50:比例 0.25 → z = 2×0.25−1 = −0.5;還原 z=0.8:x = 0+(1.8)×200/2 = 180。
第 8 講

RBF 高斯隱藏層

Yⱼ = exp( −‖x − cⱼ‖² / (2σⱼ²) )
白話
離中心越近,值越接近 1;越遠越接近 0。σ² 是寬度。
手算
c=1、σ²=0.5、x=2:‖x−c‖²=1;Y=exp(−1/(2×0.5))=e⁻¹≈0.3679。
第 8 講

k-means 更新

白話
① 每個點分給最近的中心 ② 每組的新中心 = 組內平均 ③ 重複到不動。
手算
一組點 1、2、3 → 新中心 (1+2+3)/3 = 2。
第 9 講

Hopfield 外積法與回想

W = Σₖ z⁽ᵏ⁾ z⁽ᵏ⁾ᵀ − p·I ; v = sign(W·x)
白話
W_ij = 兩個像素「是否傾向同號」(同號 +1、異號 −1,多個樣式加起來);對角線歸零避免自我強化。回想時用 W 對雜訊樣式「投票」,再取正負。
手算
z=[+1,−1,+1]:W=[[0,−1,+1],[−1,0,−1],[+1,−1,0]];輸入 x=[+1,+1,+1]:u=[0,−2,0];sign(u=0 保持原值)→ [+1,−1,+1],還原成 z。
易錯
要減 pI;u=0 保持原值;樣式要是 ±1(不是 0/1)。
第 9 講

偽逆與穩定性(只記概念)

W = V·R⁺ ; dE/dt = −Σ g′(uᵢ)(u̇ᵢ)² ≤ 0
白話
偽逆法:找 W 讓「殘缺樣式 R 進去、原樣式 V 出來」誤差最小。穩定性:能量只會降,所以一定停。
記憶
平方恆正、g′ 恆正(g 單調遞增)→ 加上負號 ≤ 0;還要 W 對稱。
