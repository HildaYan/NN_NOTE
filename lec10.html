自組織 Kohonen 網路(SOM)

Self-Organizing Kohonen Networks
← 回目錄← 上一講回目錄 →📖 術語表
版面
🌱 先用一句白話理解 前面幾乎都是「老師給答案、網路來學」。這一講完全不同:沒有答案,只有一堆資料。SOM 讓一群神經元「自己比賽、自己排隊」:每筆資料來了,最像它的神經元當贏家並往資料靠近,贏家旁邊的鄰居也被拉一點。最後這些神經元在一張二維地圖上排成貼合資料形狀的網,相近的資料落在相鄰的格子,你就能一眼看出資料有哪幾群。

摘要欄 Summary
為什麼需要 SOM?
Q1講義導入說 SOM 能把什麼變成什麼?
把複雜的輸入轉成容易理解的二維輸出(地圖)。
Q2什麼情況下只有輸入樣本、沒有期望輸出?
只拿到系統的觀測資料、沒人幫你標註答案時;這些樣本仍含有系統行為的資訊。
  • 目標:把複雜的輸入轉成容易看懂的二維輸出。
  • 有些應用只有輸入樣本、沒有對應的期望輸出;但樣本本身含有系統行為的資訊。
  • 這類問題多半用競爭式訓練讓網路「自己組織」起來。
本段重點只有輸入、沒有答案時,用競爭式學習讓網路自己整理資料。
競爭學習與贏家Competitive learning
Q1競爭學習中有幾個神經元會被活化?
只有一個,稱為「贏家(winner)」神經元。
Q2這種網路常用來做什麼?
群集分析(cluster analysis):在沒有事先分類資訊下找出資料的結構與分群關係。
  • 競爭學習:只有一個神經元被活化,它叫贏家(winner)。
  • 常用於群集分析:不靠事先的分類資訊,找出資料的結構與分群。
本段重點競爭學習只有贏家被活化,用來在無標籤資料中找分群。
SOM 是什麼?Self-Organizing Map
Q1SOM 是誰提出的?
芬蘭學者 Teuvo Kohonen(講義寫 1982,另一頁寫 1984),所以又叫 Kohonen 自組織網路。
Q2SOM 的兩個主要用途?
①當前處理器萃取資料特徵 ②做向量量化,可再接監督式方法完成樣式辨識。
Q3SOM 做的是降維嗎?
是:把高維資料映射成低維(通常二維)表示,並保留資料的拓樸結構。
  • 由芬蘭的 Teuvo Kohonen 提出(講義:1982;另一頁寫 1984),又稱 Kohonen 自組織網路。
  • 常當前處理器(萃取特徵)或做向量量化,可與監督式方法結合做樣式辨識。
  • 屬非監督式技術:把高維資料映射成低維(通常二維)表示,並保留拓樸結構。
⚠ 講義第 5 頁該段把這項技術寫成「KNN」,內容描述的其實是 SOM(KNN 是另一種監督式的 k-近鄰法);請以老師口頭說明為準。
本段重點SOM=Kohonen 提出的非監督降維網路,二維地圖保留資料拓樸。
競爭網路結構
Q1Kohonen 網路有幾層神經元層?
一般只有一層神經層(輸入層直接連到競爭層)。
Q2側向連接(lateral connection)有什麼作用?
讓神經元之間能相互影響;沒有側向連接就只調整贏家自己的權重。
  • 一般只有一層神經層(輸入 → 競爭層)。
  • 權重向量 w⁽ʲ⁾ = 第 j 個神經元連到所有輸入的權重。
  • 沒有側向連接:只有贏家自己的權重被調整 →「winner takes it all」。有側向連接:神經元之間的權重也有機會被調整。
本段重點單層、有無側向連接決定只更新贏家或連鄰居一起。
怎麼決定贏家?Distance / similarity
Q1歐氏距離公式?越大還是越小越相似?
dist = ‖x − w‖₂ = √Σ(xᵢ − wᵢ)²;越小越相似。
Q2餘弦與內積法呢?
cosθ = x·w / (‖x‖‖w‖) 與 x·w = ‖x‖‖w‖cosθ;都是越大越相似;內積還包含向量長度。
Q3n₁ 和 n 各代表什麼?
n₁ = 神經元個數;n = 輸入向量的元素個數(維度)。
distj(k) = ‖x(k) − w(j)‖₂ = √( Σᵢ₌₁ⁿ ( xᵢ(k) − wᵢ(j) )² ) , j = 1,…,n₁
  • 歐氏距離:越小越相似。
  • 餘弦夾角 cosθ = x·w /(‖x‖‖w‖):越大越相似(只看角度)。
  • 內積 x·w = ‖x‖‖w‖cosθ:越大越相似,同時含角度與向量長度。
找出「與輸入最相似」的神經元 = 贏家:winner = argminⱼ ‖x⁽ᵏ⁾ − w⁽ʲ⁾‖。
本段重點贏家=與輸入最相似者:歐氏取最小,餘弦/內積取最大。
贏家的更新規則Winner update
Q1贏家怎麼更新權重?
w⁽ᵛ⁾ ← w⁽ᵛ⁾ + η(x⁽ᵏ⁾ − w⁽ᵛ⁾),往輸入靠近一小步。
Q2為什麼更新後要正規化?
為了學習效率:每個向量除以自己的範數 ‖w‖,使所有權重落在單位圓(球)上。
Q3更新後贏家的方向如何改變?
朝輸入向量轉過去、更接近輸入。
w(v) ← w(v) + η · ( x(k) − w(v) )
  • v = 贏家;η = 學習率;只有贏家更新(沒有鄰居的版本)。
  • 更新後必須單位正規化:w ← w / ‖w‖(講義:MUST)。
  • 圖示:輸入向量、贏家、調整後神經元、更新向量、正規化——贏家被「拉近」並旋轉向輸入向量。
本段重點贏家 w←w+η(x−w) 後再除以 ‖w‖,往輸入靠近。
收斂結果與神經元數量
Q1收斂後每個權重向量在哪裡?
位在一群相似樣本的中心。
Q2群的數量由什麼決定?
由神經元數量決定;所以神經元數要靠專家經驗或統計方法估計。
  • 收斂後每個權重向量位於相似樣本群的中心。
  • 群數自動等於神經元數,所以要估計適當的神經元數(專家經驗或統計方法)。
  • 圖示:二維時向量都在單位圓內,4 個神經元對應 4 群;三維為單位球,5 個神經元對應 5 群;更高維叫超球面(hypersphere)。
  • 收斂後,新樣本進來就找最近的神經元來分類。
本段重點收斂後權重在群中心,群數=神經元數。
SOM 網格與側向連接Lateral connection
Q1SOM 的神經元怎麼排列?
排成網格(一維陣列或二維格狀),輸入層 → 競爭層 → 輸出層。
Q2側向連接的強度與距離的關係?
離贏家越近的鄰居,連接越強;越遠越弱。
  • 網狀結構的人工神經網路 + 競爭學習。
  • 側向連接:鄰居離贏家越近越強、越遠越小。
  • 形式:一維(陣列) 或 二維(網格);皆為 輸入層 → 競爭層 → 輸出層。
  • 二維網格:神經元矩陣可任意排列;空間排列決定拓樸地圖;鄰域準則決定神經元如何與鄰居合作,最常用的是涵蓋半徑 R。
本段重點SOM 把神經元排成 1D/2D 網格,鄰居按距離側向連接。
鄰域半徑 RNeighborhood
Q1R=1 時,中間的神經元有幾個鄰居?
4 個(上、下、左、右)。講義例:神經元 6 的鄰居是 {2, 5, 7, 10}。
Q2R=1.75 時為什麼多了斜角?
斜角距離 √2≈1.414 < 1.75,所以 8 個周圍神經元都被選入。
  • Ωj(R) = 第 j 個神經元、半徑 R 內的鄰居集合。
  • 講義 4×4 網格例:R=1 → 鄰居 {2, 5, 7, 10}(上下左右);R<1.75 → {1, 2, 3, 5, 7, 9, 10, 11}(含斜角,共 8 個)。
本段重點R=1 只含上下左右,R=1.75 連斜角也含。
SOM 的更新規則Rule 1 & Rule 2
Q1規則 1 與規則 2 分別更新誰?
規則 1:贏家 w⁽ᵛ⁾←w⁽ᵛ⁾+η(x−w⁽ᵛ⁾);規則 2:鄰居 w⁽Ω⁾←w⁽Ω⁾+η·α⁽Ω⁾·(x−w⁽Ω⁾)。
Q2α(鄰域算子)怎麼算?
α = exp(−‖w⁽ᵛ⁾−w⁽Ω⁾‖² / 2σ²)(高斯函數);距離越近 α 越接近 1。
Q3規則 2 比規則 1 多了什麼?
多乘了 α,所以鄰居更新量 ≤ 贏家更新量。
規則1(贏家):w(v) ← w(v) + η·( x(k) − w(v) )
規則2(鄰居):w(Ω) ← w(Ω) + η·α(Ω)·( x(k) − w(Ω) )
α(Ω) = exp( −‖w(v) − w(Ω)‖² / (2σ²) )
  • v = 贏家;Ω = 贏家鄰域內的神經元集合;α = 鄰域算子(高斯加權)。
  • 講義中 α 的距離是以權重向量 w⁽ᵛ⁾、w⁽Ω⁾ 計算。
本段重點贏家照規則1更新,鄰居再乘高斯 α 做規則2更新。
σ 隨時間變小Explore → Exploit
Q1σ(t) 的更新式?
σ(t+1) = σ₀·e^(−t/MaxIt)。
Q2σ₀=3、MaxIt=1000,t=1000 時 σ 約多少?
3e⁻¹ ≈ 1.10(講義曲線由 3 降到約 1.1)。
Q3早期與後期各稱什麼?
早期 σ 大=探索(Explore);後期 σ 小=利用(Exploit)。
α(Ω) = exp( −‖w(v)−w(Ω)‖ / 2σ(t)² ) , σ(t+1) = σ₀ · e−t / MaxIt
  • MaxIt = 最大迭代次數;t = 目前迭代;σ₀ = 初始標準差。
  • 例:σ₀=3、MaxIt=1000:σ 由 3 指數下降到約 1.1。
  • 早期(σ 大)探索 Explore:大範圍一起移動;後期(σ 小)利用 Exploit:只精修贏家附近。
⚠ 講義式中指數的分子在 σ(t) 那頁寫成 ‖w⁽ᵛ⁾−w⁽Ω⁾‖,上一頁是平方 ‖·‖²;標準寫法是平方,考試以老師板書為準。
本段重點σ(t)=σ₀e^(−t/MaxIt) 逐漸縮小:先探索、後利用。
訓練階段演算法Training phase
Q1訓練演算法的迴圈做哪幾件事?
對每個樣本:算距離 → 取最小者為贏家 → 規則1更新贏家 → 規則2更新鄰居 → 正規化;epoch+1,直到權重無明顯變化。
Q2最後兩步在做什麼?
分析地圖萃取特徵,並找出能定義類別的區域。
  1. 定義網路拓樸地圖。
  2. 建立各神經元的鄰域集合 Ω(R)。
  3. 取得訓練樣本集。
  4. 用前 n₁ 筆訓練樣本初始化各神經元權重。
  5. 正規化樣本與權重向量(w ← w/‖w‖)。
  6. 指定學習率 η。
  7. epoch ← 0。
  8. 重複:對每個樣本 ①算歐氏距離 ②winner = argminⱼ ‖x⁽ᵏ⁾−w⁽ʲ⁾‖ ③規則1更新贏家 ④規則2更新鄰居 ⑤正規化被調整的權重;epoch←epoch+1;直到權重沒有明顯變化。
  9. 分析地圖、萃取特徵。
  10. 辨識能定義類別的區域。
本段重點訓練=算距離→找贏家→更新贏家與鄰居→正規化,重複到穩定。
情境地圖與運作階段Contextual map / Operation
Q1訓練後地圖怎麼變成分類器?
把網格切成區域,每個區域定義一個類別(情境地圖,contextual map);講義例:16 個神經元分成 Class A、B、C。
Q2運作階段有幾步?
①樣本正規化 x←x/‖x‖ ②用訓練好的權重算歐氏距離 ③找贏家 ④查贏家所在區域得類別 ⑤輸出類別。
  • 地圖可切成多個區域,每區對應一類。講義例(4×4):Class A⇒{1,2,5,6,9,10};Class B⇒{3,4,7,8};Class C⇒{11,12,13,14,15,16}。
  • 運作階段(不再更新權重):①正規化 x ← x/‖x‖ ②載入訓練好的 w ③算距離、宣告贏家 ④找到贏家在地圖的位置 ⑤依所在區域指定類別 ⑥輸出類別。
本段重點分類時:新樣本→找贏家→看贏家落在哪一區就是哪一類。
手算例 1:4→2Exercise-1
Q1輸入、輸出各幾個單元?
n=4 個輸入單元、m=2 個輸出單元(降維)。
Q2鄰域設多少?為什麼?
0;因為只有 2 個輸出,只更新贏家。
Q3學習率怎麼變?
η=0.6(t=1~4),t=5~8 變成 0.5×η(1)=0.3,t=9~12 再減半…
  • 樣本:i₁=(1,1,0,0)、i₂=(0,0,0,1)、i₃=(1,0,0,0)、i₄=(0,0,1,1);樣本間(平方)距離:i₁–i₂=3、i₁–i₃=1、i₁–i₄=4、i₂–i₃=2、i₂–i₄=1、i₃–i₄=3。
  • 初始權重:Unit1=(0.2,0.6,0.5,0.9)、Unit2=(0.8,0.4,0.7,0.3)。
  • 第 1 次(i₁):d₁=1.86、d₂=0.98 → Unit 2 贏 → w₂=(0.8,0.4,0.7,0.3)+0.6×((1,1,0,0)−w₂)=(0.92, 0.76, 0.28, 0.12)。
  • 第 2 次(i₂):d₁=0.66、d₂=2.28 → Unit 1 贏 → w₁=(0.08, 0.24, 0.20, 0.96)。
  • 第 3 次(i₃):d₁=1.87、d₂=0.68 → Unit 2 贏 → w₂≈(0.97, 0.30, 0.11, 0.05)。
  • 第 4 次(i₄):d₁=0.71、d₂≈2.74 → Unit 1 贏 → w₁≈(0.03, 0.10, 0.68, 0.98)。
  • 多次 epoch 收斂後:Unit1=(0, 0, 0.5, 1.0)、Unit2=(1.0, 0.5, 0, 0)。分群結果:i₁、i₃ → Unit 2(距離 0.25);i₂、i₄ → Unit 1。
本段重點4 維降 2 維:每步算距離、贏家更新,最終 {i₁,i₃} 與 {i₂,i₄} 兩群。
手算例 2:三種相似度Exercise-2
Q1例 2 的設定?
n=2、m=2、η=0.5 固定;初始 w₁=(1,3)、w₂=(3,2);樣本 (1,1)、(3,3)、(1,2)、(2,4)。
Q2三種相似度得到的分群一樣嗎?
不一定:歐氏距離分成 Class-1/Class-2;餘弦結果不同;內積在未正規化時全歸到同一類(Class-1)。
  • 歐氏距離:迭代 1~4 贏家依序 1,2,1,2;w₁=(1,2)→(1,2),w₂=(3,2.5)→(2.5,3.25);最後 x₁、x₃→Class-1,x₂、x₄→Class-2。
  • 餘弦:贏家 2,2,1,1;最後 x₁、x₂→Class-2,x₃、x₄→Class-1。
  • 內積:贏家 2,1,1,1;最終四個樣本都被歸為 Class-1(內積含長度,長的權重向量占優)。
  • 結論:相似度的選法會影響分群;未正規化時內積最容易被向量長度左右。
本段重點同一批資料,歐氏/餘弦/內積可能分出不同的群。
SOM 範例與現象Examples 1–3
Q1均勻分佈資料,100 個神經元排成 10×10,訓練後長什麼樣?
初始混亂,隨迭代(50→1000→10000)逐漸展開成覆蓋整個正方形的規則網格。
Q2網格出現打結或扭曲怎麼辦?
換初始權重矩陣再重新訓練。
Q3資料不是均勻分佈時,神經元會怎麼分布?
神經元的分佈會反映輸入資料的機率分佈(密集處神經元較多)。
  • 例1:100 個神經元(10×10),輸入為 [0,1] 均勻分佈的二維資料;初始 → 50 → 1000 → 10000 次迭代,網格逐漸展開。
  • 有時網路會打結(tangled)或扭曲(twisted) → 換初始權重矩陣重做。
  • 例2:改成一維神經元鏈(區域改成三角形)。
  • 例3:非均勻資料(3 個高斯分布的類):神經元的機率分佈反映輸入向量的機率分佈。
本段重點網格會展開貼合資料;打結就重設初始值;神經元分布反映資料密度。

📝 摘要欄 Summary ・ 3 句話歸納本講SOM(Kohonen 自組織映射圖)是單層、非監督的競爭式網路:對每個輸入,找出與它最相似(歐氏距離最小)的「贏家」神經元,贏家依 w←w+η(x−w) 往輸入靠近並正規化。SOM 與純競爭學習的差別是神經元排成一維或二維網格,贏家的鄰居也會依高斯 α 一起更新,且標準差 σ(t) 隨時間遞減(先探索、後利用),因此能把高維資料映射成保留拓樸結構的二維地圖。訓練後把地圖分成區域定義類別(情境地圖),新樣本找贏家就能分類;但相似度的選法(歐氏/餘弦/內積)會影響結果,神經元數決定分群數,且可能打結需重設初始權重。

🎓 詳細教學(零基礎版)

1. 用「選班長」理解競爭學習

想像一個班級有 3 個「班長候選人」(神經元),每人代表一種性格(權重向量)。新同學(輸入樣本)進教室,大家比一比:誰跟這位同學最像,誰就是贏家。贏家會稍微改變自己,變得更像這位同學(w←w+η(x−w)),其他人不動。久而久之,每位候選人都變成「某一群同學的代表」——這就是分群,而且沒有人告訴過它答案(非監督)。

2. 贏家更新:往輸入靠一步

w_new = w + η(x − w)。把它看成:(x − w)是「從 w 指向 x 的箭頭」,η 是「走多遠」。η=0.6 就是走 60% 的路。這跟前面學的「新權重 = 舊權重 + η × 誤差」是同一個旋律,只是這裡的「誤差」是 x − w(輸入和代表者之間的差),沒有老師給的答案。

  1. 算輸入與每個神經元的距離(歐氏距離平方):d = Σ(xᵢ − wᵢ)²。
  2. d 最小者 = 贏家。
  3. 只更新贏家:w ← w + η(x − w)。
  4. (講義規定)更新後除以 ‖w‖ 正規化。
手算實戰:講義 Exercise-1 第 1 步 Unit1=(0.2,0.6,0.5,0.9)、Unit2=(0.8,0.4,0.7,0.3),輸入 i₁=(1,1,0,0),η=0.6。
d₁=(0.2−1)²+(0.6−1)²+0.5²+0.9²=0.64+0.16+0.25+0.81=1.86;d₂=0.04+0.36+0.49+0.09=0.98 → Unit 2 贏。
w₂ = (0.8,0.4,0.7,0.3)+0.6×(0.2,0.6,−0.7,−0.3) = (0.92,0.76,0.28,0.12)。

3. 從「競爭」進化成「SOM」:加上鄰居

純競爭只有贏家學習,神經元之間沒有「位置」概念。SOM 把神經元擺在地圖(格子)上:贏家一動,旁邊的格子也被拉過去一點,越近拉得越多。就像一張橡皮網格:你拉住其中一點,附近的點也跟著動,最後整張網貼合資料的形狀——所以相近的資料會落在地圖相鄰的位置(保留拓樸)。

純競爭學習SOM
誰更新只有贏家贏家 + 鄰居(依距離加權)
神經元位置沒有位置關係排成 1D / 2D 網格
輸出各群中心二維地圖(相近資料→相鄰格)
更新式w←w+η(x−w)贏家同左;鄰居 w←w+η·α·(x−w)

4. α 與 σ:鄰居被拉多少?

α = exp(−距離² / 2σ²) 是一條鐘形曲線(高斯):距離 0 時 α=1(跟贏家一樣多),距離越遠 α 越接近 0(幾乎不動)。σ 是鐘的「寬度」。

  1. σ 大:鐘很寬,連很遠的鄰居也被拉 → 整張地圖先大致排好(探索)。
  2. σ 小:鐘很窄,只有贏家附近動 → 精細微調(利用)。
  3. 所以 σ(t+1)=σ₀e^(−t/MaxIt) 讓 σ 由大慢慢變小。
手算:σ 與 ασ₀=3、MaxIt=1000:t=500 → σ=3e^(−0.5)≈1.82;t=1000 → σ=3e^(−1)≈1.10。若距離=2、σ=1 → α=e^(−4/2)=e^(−2)≈0.135,鄰居只被拉到贏家的約 13.5%。

5. 鄰域半徑 R 怎麼數?

把神經元當成方格的格點,相鄰格距離 1,斜角距離 √2≈1.41。所以 R=1 → 只有上下左右 4 個;R=1.75(>1.41)→ 連斜角共 8 個。角落或邊緣的神經元鄰居比較少(角落 R=1 只有 2 個)。

6. 訓練完怎麼拿來分類?

  1. 訓練:反覆「算距離 → 找贏家 → 更新贏家與鄰居 → 正規化」,直到權重不再明顯變動。
  2. 畫情境地圖:觀察地圖,把相鄰、性質相似的格子圈成區域,定義成類別(例如 Class A/B/C)。
  3. 運作:新樣本 x 先正規化 → 找離它最近的贏家神經元 → 看這格落在哪個區域 → 輸出該類別。這時不再更新權重。

9. 常見疑問

Q:SOM 的輸出是什麼?是一張二維地圖:每筆資料對應地圖上的一個格子(贏家)。相似的資料在地圖上靠近。
Q:為什麼要正規化?讓所有向量長度一致(落在單位圓/球上),這樣比較距離、餘弦與內積時不會被長度干擾,學習更有效率。
Q:神經元數要設幾個?沒有標準答案;群數由神經元數決定,所以靠專家經驗或統計方法估計。
Q:地圖打結了怎麼辦?換一組初始權重,重新訓練。
