多層感知器 MLP 與反向傳播

Multilayer Perceptron Networks (MLP) & Backpropagation
← 回目錄← 上一講下一講 →📖 術語表
版面
🌱 先用一句白話理解 MLP = 把很多個神經元排成好幾層。最大的問題是:中間層的神經元沒有「正確答案」可以比對,怎麼知道要調多少? 答案就是反向傳播:先順著網路算出輸出(前向),算出最後的誤差,再把這個「責任」一層一層往回分配給前面的權重(反向)。這是整個深度學習的心臟,也是本課程最重要的一講。

摘要欄 Summary
MLP 是什麼?
Q1MLP 的學習演算法叫什麼?別名?
反向傳播(backpropagation),也稱廣義 Delta 規則。
Q2輸出層神經元數與輸出數的關係?
一對一:m 個輸出需 m 個輸出層神經元。
屬多層前饋架構、監督式學習。輸出層可有多個神經元(m 個輸出 → m 個輸出神經元,一對一對應)。學習演算法=反向傳播(backpropagation),又稱廣義 Delta 規則。
本段重點MLP 屬多層前饋、監督式學習,以反向傳播(廣義 Delta 規則)訓練。
範例配置講義的三層
Q1此範例網路共有幾層神經元(不含輸入)?
三層:兩個隱藏層與一個輸出層。
Q2三層神經元數在講義中分別記為?
n₁(第一隱藏層)、n₂(第二隱藏層)、n₃(輸出層)。
n 個輸入 {x₁…xₙ}、第一隱藏層 n₁ 個神經元、第二隱藏層 n₂ 個、輸出層 n₃ 個信號。
本段重點範例:n 個輸入、兩層隱藏層(n₁、n₂)、n₃ 個輸出。
兩階段訓練
Q1前向與反向階段各做什麼?
前向:算輸出並與期望比較得誤差;反向:調整所有權重與閾值,降低輸出誤差總和。
Q2運作階段需要做反向嗎?
不需要,只做前向。
  • 前向階段 Forward:輸入一筆樣本 → 逐層算出輸出 → 與期望值比較 → 算出 n₃ 個誤差。
  • 反向階段 Backward:調整所有神經元的權重與閾值,目的是降低輸出誤差總和。
本段重點先前向算輸出與誤差,再反向調整所有權重與閾值。
符號系統先背熟!
Q1W_ji^(L) 中 j、i 的意義?
j=現在這一層(L)的神經元;i=前一層(L−1)的神經元。
Q2I 與 Y 的關係?
Y = g(I),I 是局部輸入(加權和),Y 是局部輸出。
Q3啟動函數有什麼要求?
必須連續且可微,一般用 logistic 或 tanh。
Wji(L)第 L 層的第 j 個神經元,接到前一層(L−1)第 i 個神經元的權重
Ij(L)第 L 層第 j 個神經元的「局部輸入」(加權和)
Yj(L)第 L 層第 j 個神經元的「局部輸出」= g(I)
Ij(L) = Σᵢ Wji(L) · Yi(L−1) , Yj(L) = g( Ij(L) )
啟動函數必須「連續且可微分」,一般用 logistic 或 tanh。第一隱藏層的 Y(0) 就是輸入 x。
本段重點Wⱼᵢ⁽ᴸ⁾:第 L 層第 j 個神經元接自前一層第 i 個;I=加權和,Y=g(I)。
誤差怎麼量?
Q1E(k) 與 E_M 差別?
E(k) 是第 k 筆樣本的平方誤差;E_M 是整個 epoch 的平均(MSE)。
Q2為什麼用 MSE 判斷收斂,而不是單筆誤差?
單筆易受個別樣本影響;MSE 反映整個 epoch 的平均表現。
  • 單一樣本:
    E(k) = ½ Σⱼ₌₁ⁿ³ ( dⱼ(k) − Yⱼ⁽³⁾(k) )²
  • 整個 epoch(p 筆):
    E_M = (1/p) Σₖ₌₁ᵖ E(k) (均方誤差 MSE)
本段重點單筆 E(k)=½Σ(d−Y)²;整個 epoch 取平均得 MSE。
反向傳播:核心想法鏈鎖律
Q1三項分別等於什麼?
∂I/∂W=前層輸出 Y;∂Y/∂I=g′(I);∂E/∂Y=−(d−Y)(輸出層)。
Q2為什麼需要鏈鎖律?
因為 E 不直接是 W 的函數,而是透過 Y 與 I 間接相依。
要算誤差 E 對某個權重 W 的偏微分,用鏈鎖律拆成 3 段相乘:
∂E/∂W = ( ∂E/∂Y ) × ( ∂Y/∂I ) × ( ∂I/∂W )
  1. #1 局部輸入對權重:∂I/∂W = 前一層的輸出 Yi(L−1)(線性代數的點積微分:∂(uᵀv)/∂v = u)
  2. #2 局部輸出對局部輸入:∂Y/∂I = g′(I)(啟動函數的一階導數)
  3. #3 誤差對局部輸出:輸出層為 −(d − Y)
本段重點鏈鎖律把 ∂E/∂W 拆成 (∂E/∂Y)(∂Y/∂I)(∂I/∂W) 三項相乘。
① 輸出層調整
Q1輸出層局部梯度 δ 的公式?
δⱼ⁽³⁾ = (dⱼ − Yⱼ⁽³⁾)·g′(Iⱼ⁽³⁾)。
Q2權重更新量由哪三者相乘?
學習率 η、局部梯度 δ、前一層輸出 Y。
局部梯度 δⱼ⁽³⁾ = ( dⱼ − Yⱼ⁽³⁾ ) · g′( Iⱼ⁽³⁾ )
Wji(3)(t+1) = Wji(3)(t) + η · δⱼ⁽³⁾ · Yᵢ⁽²⁾
沿梯度反方向更新。Yᵢ⁽²⁾=第二隱藏層第 i 個神經元的輸出。
本段重點輸出層 δ=(d−Y)g′(I);更新 W ← W + ηδY_前層。
② 隱藏層調整難點
Q1為什麼隱藏層要等輸出層調整完才能算?
因為隱藏層誤差要靠後一層的 δ 與權重估計。
Q2第二隱藏層 δ 的公式?
δⱼ⁽²⁾ = g′(Iⱼ⁽²⁾)·Σₖ δₖ⁽³⁾Wₖⱼ⁽³⁾。
Q3第一隱藏層更新用誰當 Y?
用輸入 xᵢ。
  • 隱藏層沒有直接的期望輸出;它的誤差由後一層已調整的結果「估計」出來 → 必須等輸出層做完才能調整。
第二隱藏層:δⱼ⁽²⁾ = g′( Iⱼ⁽²⁾ ) · Σₖ δₖ⁽³⁾ · Wₖⱼ⁽³⁾
Wji(2) ← Wji(2) + η · δⱼ⁽²⁾ · Yᵢ⁽¹⁾
第一隱藏層:δⱼ⁽¹⁾ = g′( Iⱼ⁽¹⁾ ) · Σₖ δₖ⁽²⁾ · Wₖⱼ⁽²⁾ ; Wji(1) ← Wji(1) + η · δⱼ⁽¹⁾ · xᵢ
重點:Σ 那項 = 把後一層的 δ,沿著連線以權重加權「倒傳回來」。
本段重點隱藏層沒有期望值,δ 由後一層的 δ 以權重加權倒傳回來。
訓練流程
Q1三層權重的調整順序?
輸出層 → 第二隱藏層 → 第一隱藏層(由後往前)。
Q2為什麼不能同時調整所有層?
隱藏層的 δ 依賴後一層已算好的 δ 與權重,必須由後往前依序計算。
前向:算每筆樣本的各層輸出。反向:先調輸出層 → 再調第 2 隱藏層 → 再調第 1 隱藏層。重複直到 E_M 夠小或達最大 epoch。
運作階段只做前向。
本段重點流程:前向→調輸出層→調第 2 隱藏層→調第 1 隱藏層,反覆至收斂。
加速法①:動量項Momentum
Q1動量項的作用?
延續上一次的調整方向,加速學習並跨過小坑。
Q2動量率 α 的範圍?動量過大會怎樣?
α∈[0,1];過大會在最佳位置附近來回震盪。
傳統法訓練太慢。加入動量:
W(t+1) = W(t) + η δ Y + α · [ W(t) − W(t−1) ] , α ∈ [0,1]
  • α·[上次的權重變化量] 就是「慣性」:延續上一個方向,加速學習。
  • 方向反了 → 動量項會轉向;動量項太大 → 在最佳點附近來回震盪。
  • 2D 圖解:小學習率→太慢;大學習率→搜尋失敗(跳過谷底);加動量→成功。
本段重點動量:W(t+1)=W+ηδY+α[W(t)−W(t−1)],用慣性加速。
加速法②:RpropResilient-Propagation
Q1Rprop 要解決什麼問題?
logistic/tanh 微分後接近 0,局部梯度小,導致更新很慢。
Q2Rprop 怎麼調學習率?
與上次斜率同號就增加(乘 >1 常數);反號就減少(乘 <1 常數)。
  • 問題:logistic/tanh 微分後在兩端接近 0,局部梯度很小,更新很慢。
  • 做法:只看梯度的「正負號(方向)」、不看大小,學習率動態調整:
    • 本次斜率與上次同號 → 學習率增加(乘以大於 1 的常數)
    • 本次斜率與上次反號(跳過最低點了)→ 學習率減少(乘以小於 1 的常數)
  • Step1 估計學習率 → Step2 以動態學習率更新權重:ΔW = η_dynamic · δ · Y。
本段重點Rprop 只看梯度正負號:同號則學習率變大,反號則變小。
加速法③:Levenberg–MarquardtLM
Q1LM 為什麼用 Jacobian 而不用 Hessian?
Jacobian 只需一階偏導,以 JᵀJ 近似 Hessian,計算較簡單。
Q2μ 大或小時,LM 像哪種方法?
μ 小像牛頓法(快);μ 大像梯度下降(穩)。
Q3J 矩陣大小?
p×M,p=樣本數,M=全部權重個數。
  • 二階梯度法,以最小平方法處理非線性模型,效率高。
  • 誤差向量 e(k) = d(k) − Y(k) 是權重 W 的函數。
  • 用Jacobian 矩陣 J(W)(一階偏導數矩陣)取代難算的 Hessian。
W(t+1) = W(t) − [ J(W)ᵀJ(W) + μI ]⁻¹ · J(W)ᵀ · E(W)
  • μI:阻尼項,I=單位矩陣。μ 小 → 像牛頓法(快);μ 大 → 像梯度下降(穩)。
  • 流程:試走一步 → 誤差變好→減小 μ(學習更「大膽」);變差→增大 μ(回退、更謹慎)。
  • J 的尺寸:p × M,M = (n+1)n₁ + (n₁+1)n₂ + (n₂+1)n₃ (全部權重個數)。
本段重點LM 是二階方法:用 Jacobian 與阻尼項 μ,W ← W−(JᵀJ+μI)⁻¹JᵀE。
牛頓法基礎
Q1牛頓法的單變數迭代式?
x_{n+1} = x_n − f(x_n)/f′(x_n)。
Q2Jacobian 不可逆怎麼辦?
改用偽逆:x_{k+1}=x_k−[JᵀJ]⁻¹Jᵀ F(x_k)。
求 f(x)=0 的根。泰勒展開省略高階:f(x) ≈ f(xₙ)+f′(xₙ)(x−xₙ)。令其為 0:
xₙ₊₁ = xₙ − f(xₙ) / f′(xₙ)
多變數:
xₖ₊₁ = xₖ − J(xₖ)⁻¹ F(xₖ)
若 J 不可逆 → 用偽逆:xₖ₊₁ = xₖ − [J(xₖ)ᵀJ(xₖ)]⁻¹ J(xₖ)ᵀ F(xₖ)。
本段重點牛頓法:x_{n+1}=x_n−f(x_n)/f′(x_n);多變數用 Jacobian 反矩陣,不可逆改用偽逆。

📝 摘要欄 Summary ・ 3 句話歸納本講MLP 是多層前饋的監督式網路,訓練分前向(算輸出與誤差)與反向(調權重)兩階段,核心是用鏈鎖律把梯度拆成前層輸出、啟動函數導數與誤差。輸出層 δ=(d−Y)g′(I),隱藏層 δ 由後一層 δ 乘權重倒傳,更新式為 W ← W + ηδY。傳統法很慢,可用動量、Rprop 或 Levenberg–Marquardt 加速,LM 以牛頓法為基礎。

🎓 詳細教學(零基礎版)

1. 用「團體報告被老師打低分」理解反向傳播

三個人接力完成報告:A 負責查資料 → B 負責整理 → C 負責簡報。老師看完給低分(輸出誤差)。

  • C 直接面對老師,最清楚自己錯在哪 = 輸出層可直接用 d − Y 調整。
  • B 沒被老師罵,但 C 說「你整理的東西讓我很難報告」,B 才知道錯 = 隱藏層的誤差是由後一層「傳回來」的。
  • A 聽 B 回報才知道要改什麼 = 再往前傳。越是參與度高(權重大)的人,被分到的「責任」越多 = δ 乘上權重。

3. 手算:最小的 MLP(1-1-1,logistic)

輸入 x=1;隱藏層 1 個神經元 W⁽¹⁾=0.5;輸出層 1 個神經元 W⁽²⁾=0.4(都忽略閾值,簡化);期望 d=1;η=0.5;g(I)=1/(1+e−I),且 g′(I)=Y(1−Y)。

  1. 前向:I₁ = 0.5×1 = 0.5 → Y₁ = g(0.5) ≈ 0.6225;I₂ = 0.4×0.6225 ≈ 0.2490 → Y₂ ≈ 0.5619。
  2. 誤差:d − Y₂ = 1 − 0.5619 = 0.4381。
  3. 輸出層 δ:g′ = 0.5619×0.4381 ≈ 0.2462 → δ₂ = 0.4381×0.2462 ≈ 0.1078。
  4. 輸出層更新:ΔW⁽²⁾ = η δ₂ Y₁ = 0.5×0.1078×0.6225 ≈ 0.0336 → W⁽²⁾ ≈ 0.4336。
  5. 隱藏層 δ(要用更新前的 W⁽²⁾=0.4):g′(I₁)=0.6225×0.3775≈0.2350 → δ₁ = 0.2350×(0.1078×0.4) ≈ 0.0101。
  6. 隱藏層更新:ΔW⁽¹⁾ = η δ₁ x = 0.5×0.0101×1 ≈ 0.0051 → W⁽¹⁾ ≈ 0.5051。
觀察輸出層權重改 0.034,隱藏層只改 0.005 —— 越靠前面,δ 被連乘的 g′(≤0.25)越多而越小。這就是梯度消失(第 1 講為何推薦 ReLU 的原因)。
⚠ 易錯計算隱藏層 δ 時,要用「更新前」的後層權重。實作時通常先把所有層的 δ 算完,再統一更新。

4. 三種加速法,各自解決什麼?

方法像什麼解決
動量滾下山的球有慣性步伐太小、遇到小坑卡住;越滾越快
Rprop只看「往哪走」,不管坡有多陡梯度太小(飽和區)更新慢
LM先用地圖算出大概落點(二階曲率資訊),再調整收斂次數少,適合中小型網路;代價是要算並存 J 矩陣、反矩陣,耗記憶體
第 7 講預告講義建議:一般用 LM 加速 MLP;但在「函數逼近」與「時變系統」問題,Rprop 通常最快。

5. 常見疑問

Q:為什麼啟動函數一定要可微?反向傳播要算 g′(I)。階梯函數的導數幾乎處處為 0,梯度傳不回去,學不動。
Q:Δw 的下標 ji 的順序會看不懂怎麼辦?記法:Wji = 「去」j ←「來」i。j 是目的地(現在這層)、i 是來源(前一層)。
Q:LM 的 J 矩陣為什麼這麼大?每一個「樣本」對每一個「權重」都要算一個偏微分,所以大小是 p × M(樣本數 × 權重總數)。權重多或資料多時非常吃記憶體,所以大型深度網路不用 LM。
Q:牛頓法跟 LM 是什麼關係?牛頓法用於找 f(x)=0 的根。把「梯度=0」當作要找的根,再用 JᵀJ 近似 Hessian,就變成高斯–牛頓法;在 JᵀJ 加上 μI 防止它不可逆,就是 Levenberg–Marquardt。
