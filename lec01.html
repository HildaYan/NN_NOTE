大腦怎麼運作?生物神經元
Q1生物神經元四個部分各對應什麼功能?
樹突=輸入、細胞體=處理、軸突=輸出、突觸=連結。
Q2生物上「訊號強弱」由什麼決定?對應人工網路的什麼?
由神經傳導物質釋放量決定;對應人工網路的「權重」。
Q3大腦約有多少神經元?每個約連多少突觸?
約 1000 億個;每個約 10,000 個突觸。
  • 大腦=超大規模平行處理系統,約 1000 億個神經元,每個神經元約連到 10,000 個突觸。
  • 構造:樹突(輸入)→ 細胞體(處理)→ 軸突(輸出)→ 突觸(連結)。
  • 多個輸入加總,超過臨界值就放出一個電脈衝(spike),沿軸突傳給下一個神經元。
  • 跨神經元傳遞靠神經傳導物質;訊號強弱取決於釋放的量 → 對應人工網路的「權重」。
  • 資訊編碼在脈衝的頻率與相位;神經元只接收「接受域 receptive field」內的訊號。
本段重點神經元由樹突收訊號、細胞體處理、軸突輸出,超過臨界值就放電。
人工神經元= 生物神經元的簡化

因為它只保留「加權加總 + 啟動」這個核心行為,忽略了生物神經元複雜的化學與時間特性。
ANN 是用軟體/硬體模擬大腦資訊處理能力的系統,由大量互連的人工神經元組成(技術上也叫 unit / node)。
平行分散模型的 8 大要素:處理單元、啟動狀態、連結(權重)、傳遞規則、啟動函數、外部輸入、學習規則、運作環境。
本段重點人工神經元是生物神經元的簡化,許多個互連就成為 ANN。

7 大特色考試常考
Q1什麼是「泛化能力」?
學習完後,對沒看過的新資料也能給出合理結果。
Q2為什麼拿掉幾個神經元網路仍可運作?
因為知識分散儲存在許多神經元與權重中(分散式儲存 + 容錯)。
Q37 大特色中哪一個和「分群」有關?
資料組織(Data organization)。
  1. 從經驗中調適:看過多個範例後調整內部參數(突觸權重)。
  2. 學習能力:能萃取資料中的關係。
  3. 泛化能力:學完後對沒看過的資料也能合理回答。
  4. 資料組織:可把有共同特徵的樣本分群。
  5. 容錯:壞掉幾個神經元也不會全盤失敗。
  6. 分散式儲存:知識分散在神經元之間。
  7. 易於實作原型:軟硬體都容易做。

分類是歸到「已定義的類別」(有標準答案);分群是自動找相似性分組(沒有標準答案)。
Q2哪一類應用適合用 Hopfield 網路?

人工神經元的 7 個零件最重要!
Q1人工神經元的 7 個零件是什麼?
輸入 x、權重 w、線性聚合器 Σ、閾值 θ、啟動電位 u、啟動函數 g、輸出 y。
Q2啟動電位 u 怎麼算?
u = Σ wᵢxᵢ − θ(加權和減閾值)。
Q3為什麼輸入要先正規化?
讓各輸入數量級相近,避免大數字主導,提高學習演算法效率。
  1. 輸入訊號 x₁…xₙ:來自外界,通常先正規化(讓學習更有效率)。
  2. 突觸權重 w₁…wₙ:衡量每個輸入對這個神經元有多重要。
  3. 線性聚合器 Σ:把「輸入×權重」全部加起來。
  4. 閾值/偏權值 θ:決定結果要多大才會觸發輸出。
  5. 啟動電位 u = Σ − θ。
  6. 啟動函數 g(·):把輸出限制在合理範圍。
  7. 輸出訊號 y = g(u),也可作為下一個神經元的輸入。
u = Σᵢ wᵢxᵢ − θ , y = g(u) (McCulloch & Pitts, 1943)
本段重點u = Σwx − θ,y = g(u):輸入×權重加總、減閾值,再過啟動函數。
啟動函數分兩類
Q1Logistic 與 tanh 的輸出範圍各是多少?
Logistic:0~1;tanh:−1~+1。
Q2為什麼「可微」對學習很重要?
反向傳播需要啟動函數的導數(斜率)來決定權重調整方向;階梯函數處處斜率 0,無法學習。
Q3高斯函數中 c 與 σ 各代表什麼?
c = 中心;σ = 標準差(決定寬窄)。
① 部分可微(有些點微不了):階梯函數(硬限制器)、雙極階梯函數(符號函數)、對稱斜坡函數、ReLU。
② 全可微(每點都能微分):線性、邏輯(logistic)、雙曲正切(tanh)、高斯。
函數公式輸出範圍
階梯u≥0 → 1,否則 00 或 1
雙極階梯(sign)u≥0 → +1,否則 −1−1 或 +1
線性g(u)=u無限制
Logistic1/(1+e−βu);β=1 即 sigmoid0 ~ 1
Tanh(1−e−βu)/(1+e−βu);β=2 即 tanh−1 ~ +1
Gaussianexp(−(u−c)²/2σ²),c=中心,σ=標準差0 ~ 1(中心最大)
ReLUmax(0,u)0 ~ ∞
本段重點啟動函數分「部分可微」(階梯、sign、斜坡、ReLU)與「全可微」(線性、logistic、tanh、高斯)。
為何深度學習愛用 ReLU?4 個理由
Q1ReLU 為何能緩解梯度消失?
正區斜率恆為 1,不像 sigmoid/tanh 兩端斜率接近 0。
Q2ReLU 的「稀疏性」有什麼好處?
負值輸出為 0,許多神經元不啟動,有助避免過擬合。
Q3ReLU 的計算為什麼省?
只需比較大小(max(0,u)),沒有指數運算。
  1. 避免梯度消失:sigmoid/tanh 在兩端很平(斜率≈0),反向傳播時學不動;ReLU 正區斜率恆為 1。
  2. 稀疏性:負數全變 0,許多神經元「休息」,有助避免過擬合。
  3. 像生物:低於門檻就不啟動。
  4. 計算量小:只是比大小,沒有指數運算。
本段重點ReLU 流行是因為不梯度消失、稀疏、像生物、計算快。

🎓 詳細教學(零基礎版)

1. 用「評審團」理解一個神經元

想像你要決定「今天要不要出門野餐」,你問了三個朋友的意見:天氣預報(x₁)、心情(x₂)、有沒有伴(x₃)。你不是平等地看待每個意見:你很信任天氣預報,所以給它大權重 w₁=0.7;心情只佔 0.2;有沒有伴 0.1。

  1. 輸入:三個意見打分數,例如 x=(0.9, 0.5, 0.0)。
  2. 乘權重再加總:Σ = 0.7×0.9 + 0.2×0.5 + 0.1×0 = 0.63+0.10 = 0.73。
  3. 減門檻:你要求至少 0.5 分才出門(θ=0.5),所以 u = 0.73 − 0.5 = 0.23。
  4. 啟動函數:用階梯函數,u≥0 就輸出 1(出門),否則 0(不去)。結果 y=1。
🔑 整個神經網路就是這件事的重複學習 = 自動找出最合適的「權重」和「門檻」,不用人工設定。

2. 為什麼需要「啟動函數」?

如果沒有啟動函數,不管疊幾層,整個網路都只是一堆加法與乘法 = 一條直線。啟動函數加入「彎曲」,網路才能學習曲線和複雜圖形。另外它也把輸出壓在合理範圍(例如 0~1),避免數字爆炸。

三種常見啟動函數長相:硬切、平滑 S 形、負的歸零正的直上

3. 「部分可微」和「全可微」到底差在哪?

「可微」白話就是「這條曲線每個點都有明確的坡度」。後面要學的反向傳播要靠坡度告訴網路「權重往哪個方向調」,所以:

  • 階梯函數在跳躍點沒有坡度、其他地方坡度又是 0 → 沒辦法用坡度學習(所以早期感知器用別的學習規則)。
  • Sigmoid、tanh 處處有坡度 → 後面的 MLP 愛用。
  • ReLU 在 0 點有個尖角(不可微),但實務上直接規定該點坡度為 0 或 1 就能用。

4. 逐項記住歷史:一個故事版

1943 有人先用數學描述「神經元」→ 1957 Rosenblatt 做出真的能學習的感知器,還造了機器 Mark I → 但只有一層,很多問題解不了 → 1960 起有人嘗試多層,但不知道怎麼訓練 → 1974、1986 反向傳播出現,多層網路才真正好用 → 同時期有人往別的方向走:Hopfield(會記憶)、Kohonen SOM(會自己分群)、RBF(用高斯函數)。

記憶口訣「四三(1943)神經元,五七(1957)感知器,七四(1974)反傳播,八二(1982)霍普菲爾,八六(1986)大突破,八八(1988)RBF」。

5. 常見疑問

Q:閾值 θ 和偏權值 bias 是一樣的嗎?基本上是同一件事,只是正負號不同。講義寫 u = Σ − θ;很多書寫成 u = Σ + b,b = −θ。後面講義會把 −θ 當成第 0 個輸入(固定輸入 −1,權重是 θ),這樣整個式子可以寫成一個向量乘法。
Q:為什麼輸入要先正規化?如果一個輸入是身高(170)另一個是溫度(0.3),大的數字會主導加總,學習會很慢甚至失敗。正規化把所有輸入縮到相近範圍(例如 −1~1)。
Q:神經網路為何有「容錯」?因為知識分散在很多權重裡,不是存在某一個特定位置。就像拿掉一塊拼圖,你仍然看得出整張圖大概是什麼。
Q:Gaussian 函數為什麼特別?它是「靠近中心 c 時輸出接近 1,越遠越接近 0」的鐘形曲線,代表「這個輸入和我的中心有多像」。這個特性會在第 8 講 RBF 網路裡大放異彩。
