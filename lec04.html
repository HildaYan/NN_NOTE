ADALINE 網路與 Delta 規則

ADALINE Network and Delta Rule

版面
🌱 先用一句白話理解 ADALINE 和感知器長得幾乎一樣,差別在「怎麼學」:感知器只問「分對了沒?」(對/錯),ADALINE 問的是「離正確答案差多遠?」(差多少就調多少)。這種「順著坡度往下走、讓誤差越來越小」的想法,就是後面所有神經網路(包含 MLP、深度學習)訓練方法的雛形。

Q1ADALINE 全名與發明者?
Adaptive Linear Element;Widrow 與 Hoff,1960。
Q2MADALINE 是什麼?
Multiple ADALINE,多個 ADALINE 的延伸版本(Widrow & Winter 1988)。
  • Adaptive Linear Element,Widrow & Hoff 於 1960 發表。

  • 延伸版本:MADALINE(Multiple ADALINE,Widrow & Winter 1988)。
本段重點ADALINE(1960)結構同感知器,是單層單神經元,延伸有 MADALINE。
結構
Q1ADALINE 有幾個神經元、幾個輸出?
各一個,只能輸出兩類。
Q2ADALINE 的 u 與 y 的關係?
y = g(u),u 是啟動電位,y 是啟動函數之後的輸出。
n 個輸入 xᵢ、n 個權重 wᵢ、一個神經元、一個輸出;啟動電位 u,啟動函數 g(·);輸出只有兩類。
u = Σᵢ wᵢxᵢ − θ , y = g(u)
本段重點n 個輸入、n 個權重、一個神經元、一個輸出,u=Σwx−θ。
跟感知器差在哪?必考
Q1感知器與 ADALINE 的差別?
只在學習規則:感知器用啟動後輸出 y 的對錯;ADALINE 用啟動前電位 u 與期望 d 的差(連續值)。
Q2為什麼用 u 而不用 y 較好?
u 是連續值,誤差有大小,可微分、可做梯度下降。
只差在「學習規則」(用來調權重與閾值的方法)。
感知器ADALINE
誤差用誰算啟動函數之後的輸出 y(±1)啟動函數之前的電位 u(連續值)
誤差性質只有 0 或 ±2連續、有大小
學習規則誤差修正Delta 規則 / LMS
本段重點與感知器唯一差別是學習規則:ADALINE 用啟動前電位 u 算連續誤差。
訓練架構誤差訊號
Q1ADALINE 的誤差訊號怎麼定義?
error = d − u(期望值減啟動電位)。
Q2誤差訊號在啟動函數之前還是之後取得?
之前(用 u,而不是 y)。
給定期望值 d,與啟動電位 u 比較,得到誤差訊號 error = d − u,再依誤差調整權重。
本段重點誤差訊號 error = d − u,依誤差調整權重。
學習演算法的別名
Q1Delta 規則還有哪些別名?
Widrow-Hoff 學習規則、LMS(最小均方)演算法、梯度下降法。
Q2這些別名中,哪個名稱強調「最小化均方誤差」?
LMS(Least Mean Square)。
Delta 規則(Widrow & Hoff 1960) = Widrow-Hoff 學習規則 = LMS(Least Mean Square)演算法 = 梯度下降法(Gradient Descent)。
本段重點Delta 規則=Widrow-Hoff=LMS=梯度下降,是同一件事的不同名稱。
Delta 規則目標
Q1Delta 規則的策略是什麼?
在 p 筆訓練樣本下,最小化 d 與線性組合器回應 u 的差。
Q2最佳權重 w* 是什麼樣的權重?
使平方誤差 E(w) 最小的權重。
有 p 筆訓練樣本時,最小化期望輸出 d 與線性組合器回應 u 的差,找出最佳權重 w*。
本段重點目標:最小化期望輸出 d 與電位 u 的差,找最佳 w*。
平方誤差函數E(w)
Q1E(w) 中每個符號代表什麼?
p=訓練筆數;d⁽ᵏ⁾=第 k 筆期望;u⁽ᵏ⁾=第 k 筆電位。
Q2為什麼取平方?
讓誤差恆為正且可微分,大誤差被放大懲罰。
E(w) = ½ Σₖ₌₁ᵖ ( d⁽ᵏ⁾ − u⁽ᵏ⁾ )²
其中 u⁽ᵏ⁾ = Σⱼ wⱼxⱼ⁽ᵏ⁾ − θ = wᵀx⁽ᵏ⁾(向量化)。p=訓練筆數、d⁽ᵏ⁾=第 k 筆期望值、u⁽ᵏ⁾=第 k 筆電位。
本段重點E(w)=½Σ(d−u)²:p 筆誤差平方和的一半。
梯度推導為什麼有 ½
Q1為什麼 E 前面要乘 ½?
微分時平方的 2 會與 ½ 抵消,式子較簡潔。
Q2為什麼更新式是「+」而不是「−」?
梯度本身為 −Σ(d−u)x;「減去梯度」負負得正,所以寫成加號。
  1. 要找 E 的最小值 → 用梯度(多變數的偏微分向量)找下坡方向。
  2. E 對 w 微分(鏈鎖律),½ 與平方的 2 抵消:
    ∇E(w) = − Σₖ ( d⁽ᵏ⁾ − u⁽ᵏ⁾ ) · x⁽ᵏ⁾
  3. 朝梯度的反方向走(負號):
    Δw = η Σₖ ( d⁽ᵏ⁾ − u⁽ᵏ⁾ ) · x⁽ᵏ⁾
本段重點∇E = −Σ(d−u)x;朝梯度反方向走得 Δw = ηΣ(d−u)x。
權重更新公式
Q1x⁽ᵏ⁾ 的第一項為何是 −1?
把閾值 θ 併入權重向量(w 第一項為 θ),使 u=wᵀx。
Q2η 的範圍?
0<η<1。
w_new = w_old + η Σₖ ( d⁽ᵏ⁾ − u⁽ᵏ⁾ ) x⁽ᵏ⁾
演算法寫法(逐筆):
w ← w + η · ( d⁽ᵏ⁾ − u⁽ᵏ⁾ ) · x⁽ᵏ⁾ , k = 1,2,…,p
  • w = [θ, w₁, …, wₙ]ᵀ(閾值與權重合在一起)
  • x⁽ᵏ⁾ = [−1, x₁⁽ᵏ⁾, …, xₙ⁽ᵏ⁾]ᵀ(第 k 筆樣本,第一項固定 −1)
  • η:學習率,0<η<1
本段重點更新式:w ← w + η(d−u)x,其中 x 第一項固定 −1 代表閾值。
幾何意義
Q1Delta 規則的幾何意義?
權重沿誤差曲面的負梯度逐步移向最小平方誤差的位置。
Q2越接近最小點,更新量會怎樣?
梯度愈小,更新量也愈小。
誤差曲面像一個「碗」;權重從初始位置出發,每次沿著坡度往下走一步,最後落到碗底(最小平方誤差)。決策線也隨之從初始位置慢慢移動到最佳位置。負號 = 與梯度方向相反。
本段重點像下山:每步沿坡度最陡的反方向走,直到谷底。
停止條件MSE
Q1如何判定 ADALINE 已收斂?
相鄰兩個 epoch 的 MSE 之差小於門檻 ε。
Q2MSE 曲線最後長什麼樣?
趨近一個固定常數(碰到最小值)。
MSE = (1/p) Σₖ ( d⁽ᵏ⁾ − u⁽ᵏ⁾ )² ; | MSE_now − MSE_prev | ≤ ε
相鄰兩個 epoch 的 MSE 差距小於精度門檻 ε 就視為收斂。MSE 曲線最後會趨於一個固定值。
本段重點以相鄰兩個 epoch 的 MSE 差 ≤ ε 作為收斂判斷。
演算法流程
Q1訓練階段與運作階段差別?
訓練會更新 w;運作階段只算 u=wᵀx 並輸出 y=g(u)。
Q2訓練需要期望值 d 嗎?運作需要嗎?
訓練需要;運作不需要。
訓練:取得樣本與 d → 設 η、ε,隨機初始化 w → 重複(逐筆更新 w;計算 MSE)直到收斂。
運作:取得新樣本 → 算 u = wᵀx → y = g(u)。
本段重點訓練:逐筆更新 w 並算 MSE 直到收斂;運作:u=wᵀx 再過 g。

📝 摘要欄 Summary ・ 3 句話歸納本講ADALINE(1960)的結構與感知器相同,差別只在學習規則,它用啟動前電位 u 計算連續誤差 d−u。Delta 規則(又稱 LMS、梯度下降)定義平方誤差 E(w)=½Σ(d−u)²,求梯度後沿反方向更新 w ← w + η(d−u)x。當相鄰兩個 epoch 的 MSE 差小於 ε 即停止,這個觀念是 MLP 反向傳播的基礎。

🎓 詳細教學(零基礎版)

1. 「下山」比喻:什麼是梯度下降?

你被蒙眼丟在山坡上,想走到最低的山谷。你的做法:用腳感受哪個方向往下傾斜最陡,朝那邊走一小步,再感受,再走…。

  • 山的高度 = 誤差 E(w)
  • 你站的位置 = 目前的權重 w
  • 腳感受的坡度 = 梯度 ∇E
  • 一步的大小 = 學習率 η

2. 為什麼 ADALINE 比感知器「聰明」?

感知器分錯的時候只知道「錯了」,而且錯 1 分和錯 100 分,在它眼裡都是一樣的錯。ADALINE 看的是錯得有多離譜:差很多就大幅調整,差一點點就微調。這樣學習更平順,也讓數學上可以用微分。

3. 手算一步 Delta 規則

設 η=0.1;某筆樣本 x=[−1, 1, 2]ᵀ,期望 d=1;當前 w=[0.5, 0.2, 0.1]ᵀ。

  1. 算電位:u = wᵀx = 0.5×(−1) + 0.2×1 + 0.1×2 = −0.5+0.2+0.2 = −0.1。
  2. 算誤差:d − u = 1 − (−0.1) = 1.1。
  3. 算調整量:Δw = η(d−u)x = 0.1×1.1×[−1,1,2] = [−0.11, 0.11, 0.22]。
  4. 更新:w = [0.39, 0.31, 0.32]。
  5. 驗證:新的 u = −0.39+0.31+0.64 = 0.56,誤差變成 0.44(原本 1.1)→ 變小了!
規律同一筆樣本的誤差會乘上 (1 − η‖x‖²)。這裡 ‖x‖²=6,η=0.1 → 乘 0.4,所以 1.1→0.44 ✓。η 太大(讓係數 < −1)就會越調越錯,這是為什麼 η 要小。

4. 為什麼更新公式前面有「+」,不是「−」?

梯度下降的標準寫法是 w ← w − η∇E。而 ∇E 本身是 −Σ(d−u)x,負負得正,所以寫成 w ← w + η(d−u)x。「+」和「減梯度」是同一件事,不要被符號搞混。

6. 常見疑問

Q:為什麼 x 的第一項固定是 −1?這是把閾值 θ「藏」進權重向量的技巧:u = w₁x₁+…+wₙxₙ − θ。令 x₀=−1、w₀=θ,就能寫成 u = Σⱼ₌₀ⁿ wⱼxⱼ = wᵀx,更新公式不必另外處理 θ。
Q:ADALINE 能解 XOR 嗎?不能。它仍然是單層、單神經元,只能畫直線。需要 MLP。
Q:停止條件為什麼不用「誤差 = 0」?實際資料有雜訊,誤差通常不可能到 0;所以看「誤差不再明顯變小」(相鄰 epoch MSE 差 ≤ ε)。
