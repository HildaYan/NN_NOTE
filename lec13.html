🌱 先用一句白話理解 ART 像會「自己開新資料夾」的分類員:新資料先找最像的類別,夠像才放進去;都不夠像就新增一類。所以學新東西時,舊知識不會被蓋掉。

ART-1 拓樸F⁽¹⁾ / F⁽²⁾
Q1兩層名稱與用途?
F⁽¹⁾ 比較層(特徵辨識);F⁽²⁾ 辨識層(類別辨識)。
Q2兩組權重各是什麼?
W⁽ᶠ⁾ 前饋(F1→F2),實數;W⁽ᵇ⁾ 回饋(F2→F1),二元。
Q3各層神經元數?
F⁽¹⁾ = 輸入向量維度;F⁽²⁾ 動態,依類別數增加。
  • 輸入向量是二元。
  • 所有神經元雙向連接。
  • F⁽¹⁾:比較輸入與已存向量的相似度。
  • F⁽²⁾:把輸入歸到某一類;層內有側向連接彼此競爭;與 SOM 一樣一次只有一個神經元活化。
本段重點比較層+辨識層;W(f) 實數、W(b) 二元。
六大階段流程圖
Q1依序是哪六個?
①初始化 ②辨識 ③比較 ④搜尋 ⑤更新 ⑥提供類別。
  1. Initialization:初始化權重矩陣與警戒參數。
  2. Recognition:競爭法找目前贏家。
  3. Comparison:對警戒參數做相似度測試;不過就停用贏家。
  4. Search:還有神經元就回②;沒有就新增。
  5. Update:調整 W⁽ᶠ⁾、W⁽ᵇ⁾。
  6. Provision:輸出類別標籤。
本段重點初→辨→比→搜→更→供。
① 初始化ρ
Q1W⁽ᶠ⁾、W⁽ᵇ⁾ 初始值?
W⁽ᶠ⁾ = 1/(1+n);W⁽ᵇ⁾ = 1。
Q2為什麼 W⁽ᶠ⁾ 要小?
避免飽和。
Q3ρ 的範圍與影響?
0 < ρ < 1;越大越嚴格(看更多細節),越小判別力越寬鬆。
Wji(f) = 1/(1+n) , Wij(b) = 1 , i = 1…n, j = 1…m
  • n:F⁽¹⁾ 神經元數;m:F⁽²⁾ 已啟用神經元數。
  • W⁽ᵇ⁾ 全 1 代表 F⁽²⁾ 每個神經元都啟用、可把回應送到 F⁽¹⁾。
本段重點W(f)=1/(1+n)、W(b)=1、0<ρ<1。
② 辨識Recognition
Q1活化值怎麼算?贏家怎麼選?
uj = Σ Wji(f)·xi;k = argmax uj。
Q2輸出?
贏家 y = 1,其餘 0(贏者全拿)。
uj = Σᵢ₌₁ⁿ Wji(f)·xi , k = arg maxⱼ {uj} , yj = 1 (j = k),0 (j ≠ k)
  • 類似 Kohonen 的競爭法。
  • 贏家代表輸入可能所屬的候選類別。
本段重點u 最大者是候選類別。
③ 比較相似度 R
Q1R 怎麼算?
共同的 1 的個數 ÷ x 裡 1 的個數。
Q2通過條件?
R > ρ 通過;R ≤ ρ 不通過。
R = Σⱼ Wjk(b)·xj / Σⱼ xj
  • 把贏家的回饋向量 W(b)·k 送回 F⁽¹⁾,和 x 比較。
  • 講義例:x = [1,0,1,1,0,1,0,1],W⁽ᵇ⁾ = [1,0,1,0,0,1,1,1] → R = 4/5 = 0.8。
  • R > ρ:該類別適合,進第⑤階段更新。
  • R ≤ ρ:該神經元和輸入差太多,把機會讓給其他神經元。
本段重點R=共同1/輸入1;R>ρ 才收。
④ 搜尋Search
Q1測試失敗後怎麼做?
停用贏家(uk = 0),重複 ②③④。
Q2完全沒有相似的?
代表是新類別 → 在 F⁽²⁾ 新增神經元。
Q3新增神經元的兩種資料結構?
靜態(固定最大數量+啟用狀態標記)、動態(鏈結串列)。
靜態 Static動態 Dynamic
大小固定上限(例:50)可變
狀態標記需要 Active/Inactive不需要
實作陣列依序啟用link-list,用指標串接
本段重點停用→再找→都不行就新增。
⑤ 更新Update
Q1W⁽ᵇ⁾ 更新式?
Wjk(b)(t+1) = Wjk(b)(t)·xj(等於 AND 閘)。
Q2W⁽ᶠ⁾ 更新式?
Wkj(f)(t+1) = Wjk(b)(t)xj / (½ + Σ Wik(b)(t)xi)。
Q3更新誰?
只更新與贏家 k 有關的元素。
Wjk(b)(t+1) = Wjk(b)(t)·xj
Wkj(f)(t+1) = Wjk(b)(t)·xj / ( ½ + Σᵢ₌₁ⁿ Wik(b)(t)·xi )
  • 講義例:W⁽ᵇ⁾·2 = [1,0,0,1,1,1,0,1],x = [1,0,1,1,1,0,1,1] → 新 W⁽ᵇ⁾ = [1,0,0,1,1,0,0,1]。
  • 新 W⁽ᶠ⁾ = [2/9,0,0,2/9,2/9,0,0,2/9],因為 1/(0.5+4) = 2/9。
  • W(b)jk 與 W(f)kj 是同一對神經元之間的兩個方向。
本段重點W(b) 做 AND;W(f) 是它除以 0.5+個數。
⑥ 提供與完整演算法Provision
Q1訓練後怎麼分類?
用辨識階段的式子取贏家,輸出二元字串。
Q2一筆樣本的迴圈何時結束?結束後做什麼?
Winner =「Approved」時結束;然後重新啟用 F⁽²⁾ 所有神經元。
  1. 輸入 x。
  2. 初始化 W⁽ᶠ⁾、W⁽ᵇ⁾。
  3. 指定 ρ。
  4. 重複:算 u → 取贏家 k → 算 R;若 R>ρ:更新、歸類、Approved;若 R≤ρ 且還有神經元:停用 k(uk=0)、Reproved;若 R≤ρ 且沒有神經元:新增、更新、歸類、Approved;直到 Approved。
  5. 重新啟用 F⁽²⁾ 全部神經元。
本段重點Approved 才停;結束後解除停用。

🎓 詳細教學(零基礎版)

1. 白話:一位很挑剔的圖書管理員

每來一本新書(二元特徵向量),管理員先找最像的書櫃(辨識),再檢查是不是真的夠像(比較,R > ρ?)。夠像就放進去、更新書櫃標籤(更新);不夠像就換下一個書櫃(搜尋);全部都不像就買新書櫃。因為舊書櫃不會被硬改成不相干的內容,所以「學新的、不忘舊的」。

3. 手算:講義例題(p.31–33,逐步)

一、題目F⁽¹⁾ 有 8 個神經元,贏家 k = 2。
x = [1, 0, 1, 1, 1, 0, 1, 1]
W⁽ᵇ⁾·2(t) = [1, 0, 0, 1, 1, 1, 0, 1]
二、第一步:相似度
  • 兩者同時是 1 的位置:1、4、5、8 → 4 個
  • x 裡 1 的個數:6
  • R = 4/6 ≈ 0.667
  • ρ = 0.4 → 通過;ρ = 0.7 → 不通過
三、第二步:更新回饋權重(假設通過)
  • 逐位做 AND:兩邊都是 1 才是 1
  • W⁽ᵇ⁾(t+1) = [1, 0, 0, 1, 1, 0, 0, 1]
四、第三步:更新前饋權重
  • 分母 = 0.5 + 4 = 4.5
  • 是 1 的位置:1/4.5 = 2/9;其他 0
五、考試快速記憶分子是「更新後那一格」,分母是「0.5 + 更新後 1 的總數」。

7. 常見疑問

Q:u 最大不就一定最像嗎?為什麼還要算 R?u 是用標準化後的權重打分,選出「候選」;R 才檢查這個候選是否達到最低相似標準。沒達標就換人。
Q:停用的神經元之後怎麼辦?只在這一筆樣本期間停用;處理完(Approved)後全部重新啟用。
Q:樣本順序有影響嗎?由更新式可看出權重依先後做 AND,通常順序不同可能得到不同分群(講義沒有明講,屬延伸理解)。
