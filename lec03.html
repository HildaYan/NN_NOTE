Rosenblatt 感知器

Rosenblatt's Perceptron
← 回目錄← 上一講下一講 →📖 術語表
版面
🌱 先用一句白話理解 感知器是最簡單的神經網路:只有一個神經元。它的工作是在平面上畫一條直線,把兩種點分開。如果它分錯了,就「把線推向正確的那一邊」,一直推到全部分對為止。而且數學上保證:只要資料「真的能被一條直線分開」,它一定會停下來(收斂)。

誰發明的?
Q1感知器是誰在哪一年發表?
Rosenblatt,1958(講義寫 1st published in 1958)。

他是心理學家,但啟發了工程師、物理學家與數學家投入研究。

本段重點Rosenblatt 是心理學家,1958 發表感知器,稱為深度學習之父。
感知器是什麼?
Q1感知器由哪三部分組成?
單一神經元、可調突觸權重、偏權值(bias)。
Q2感知器收斂定理說了什麼?
只要兩類樣本線性可分,感知器演算法必會收斂,並在兩類之間放置超平面。
  • 神經網路最簡單的形式:單一神經元 + 可調突觸權重 + 偏權值(bias)。
  • 用來分類線性可分(linearly separable)的樣式。
  • 感知器收斂定理:若訓練樣本來自兩個線性可分的類別,則演算法一定收斂,並在兩類之間放一個超平面(決策面)。
本段重點感知器=單一神經元+可調權重+偏權值,用來分類線性可分的資料。
輸出與決策邊界
Q1二變數時決策邊界公式?
x₂ = −(w₁/w₂)x₁ + θ/w₂(一條直線)。
Q2y=+1 與 y=−1 各表示什麼?
分別表示屬於類別 𝒞₁ 與 𝒞₂。
目的:用輸入 (x₁…xₘ) 把資料分成 𝒞₁ 與 𝒞₂ 兩類。
y = +1 (屬於 𝒞₁) ; y = −1 (屬於 𝒞₂)
Σᵢ wᵢxᵢ − θ = 0 (決策邊界/超平面)
二變數時:
x₂ = −(w₁/w₂)·x₁ + θ/w₂ (一條直線)
本段重點輸出 y=±1 表兩類;決策邊界是 wᵀx−θ=0,二維為一條直線。
限制必考
Q1為什麼感知器解不了 XOR?
XOR 的資料不是線性可分,無法用一條直線分開。
Q2怎麼讓感知器分多於兩類?
把輸出層擴充成多個神經元。
  • 只能處理線性問題(邊界必須是直線)。
  • 一個神經元只能分兩類。
  • 想分多類 → 把輸出層擴充成多個神經元。
典型解不了的例子:XOR(第 6 講用 MLP 解)。
本段重點限制:只能解線性問題、單一神經元只分兩類。
符號整理收斂定理用
Q1為什麼要把偏權值併入權重向量?
讓整個運算與更新規則可用單一向量式表示,方便推導。
Q2n 代表什麼?
迭代次數(時間標記)。
  • 輸入向量 x(n) = [−1 或 +1(偏權值項), x₁(n), …, xₘ(n)]ᵀ
  • 權重向量 w(n) = [b, w₁(n), …, wₘ(n)]ᵀ(把偏權值 b 當成 w₀)
  • 線性組合輸出 v(n) = wᵀ(n)x(n);超平面 wᵀx = 0。
  • n = 迭代次數(時間標記)。
本段重點把偏權值併入權重向量 w₀,輸入補一個固定項,使 u=wᵀx。
更新規則誤差修正學習
Q1更新規則何時觸發?
只有分類錯誤時才更新;分對則 w(n+1)=w(n)。
Q2η 的範圍?固定 η 叫什麼規則?
0<η≤1;固定 η 稱為固定增量調整規則。
Q3d−y 的值可能有哪些?
分對為 0;分錯為 ±2(因 d、y 皆為 ±1)。
  • 若 wᵀx(n) > 0 且 x 屬於 𝒞₁,或 wᵀx ≤ 0 且 x 屬於 𝒞₂ → 分對了,不更新:w(n+1)=w(n)。
  • 否則分錯 → 更新:
w(n+1) = w(n) + η·[d(n) − y(n)]·x(n)
d=期望輸出,y=實際輸出,η=學習率(0<η≤1)。η 固定 = 「固定增量調整規則」。
本段重點分錯就更新:w(n+1) = w(n) + η[d(n)−y(n)]x(n);分對不動。
收斂定理證明核心思路
Q1證明收斂時用到哪個不等式?
Cauchy–Schwarz 不等式。
Q2為什麼下界 n² 與上界 n 能推出收斂?
n² 成長比 n 快,兩者只在 n 有限時才能同時成立,所以更新次數有最大值 n_max。
Q3初始權重不是 0 還會收斂嗎?
會,只是迭代次數可能增減。
  1. 假設 w(0)=0、η=1,且存在一組正確解 w₀。
  2. 定義 α = min w₀ᵀx(n) > 0。
  3. 用 Cauchy–Schwarz 不等式得下界:‖w(n+1)‖² ≥ n²α² / ‖w₀‖²(隨 n² 成長)。
  4. 把更新式取平方範數得上界:‖w(n+1)‖² ≤ nβ,β = max‖x‖²(只隨 n 線性成長)。
  5. 下界 n² 追上上界 n 一定有交會點 → n 有最大值 n_max = β‖w₀‖²/α²,更新次數有限 → 收斂。
初始權重不為 0 只會改變所需次數,仍保證收斂。
本段重點下界隨 n² 成長、上界隨 n 成長,故更新次數有上限,保證收斂。
學習率 η 的影響
Q1小 η 與大 η 各有什麼特性?
小 η:平均過去輸入,權重估計穩定;大 η:快速適應變化。
Q2若資料常變動、想快速適應,η 該偏大還是偏小?
偏大;但太大可能不穩,需要權衡。
  • 小 η:會平均過去的輸入,權重估計穩定、但慢。
  • 大 η:適應變化快、但可能不穩。
本段重點η 小:穩定但慢;η 大:適應快但可能不穩。
演算法流程
Q1感知器的訓練在何時停止?
某個 epoch 中所有樣本都被分對(沒有更新)。
Q2訓練與運作兩階段差別?
訓練會更新權重;運作只用固定權重做前向計算。
訓練:① 取得訓練樣本 {x(k)} 與期望 {d(k)} ② 設 η、隨機初始化 w ③ 逐筆算 u=wᵀx、y=sign(u),若 y≠d 就更新 ④ 重複 epoch,直到沒有任何錯誤。
運作:取得新樣本 → 算 u → y=sign(u) 即得分類結果。
本段重點流程:初始化 → 逐筆判斷分錯就更新 → 重複至全對;運作時只做 sign(wᵀx)。
實驗:雙月分類
Q1雙月實驗的訓練/測試資料量?
訓練 1,000 對、測試 2,000 對。
Q2為什麼月牙靠近時錯誤率會升?
資料不再線性可分,單一直線無法完全分開。
Double-moon 問題:兩個月牙形隨機點,各選 1000 對訓練、2000 對測試,輸入層 2 個節點,學習率 10⁻¹~10⁻⁶。當兩月牙距離拉近、不再線性可分時,感知器分類誤差變大(一個設定下約 9.3%)。
本段重點雙月實驗:線性可分時表現好,距離縮小變不可分則誤差升高(約 9.3%)。
批次感知器代價函數版
Q1為什麼要定義代價函數?
代價函數可微分,能用梯度做最陡下降,為後續 ADALINE/MLP 奠基。
Q2J(w)=0 代表什麼?
所有樣本都分類正確(分錯集合為空)。
Q3批次更新式?
w(n+1) = w(n) + η(n)·Σ_{x∈ℋ} x(沿梯度反方向)。
  • 定義代價函數 J(w) = Σ_{x∈ℋ} (−wᵀx)(ℋ=被 w 分錯的樣本集合;全對時 ℋ 為空,J=0)。
  • 目標:最小化 J(w)。因為是數學式,所以可對 w 微分。
  • 梯度 ∇J(w) = Σ_{x∈ℋ}(−x)。
  • 用最陡下降法更新:w(n+1) = w(n) + η(n) Σ_{x∈ℋ} x(沿梯度的反方向)。
本段重點批次版以代價函數 J(w)=Σ(−wᵀx) 最小化,用最陡下降法更新。

🎓 詳細教學(零基礎版)

1. 「直線分兩邊」是什麼意思?

在紙上畫紅點和藍點。如果能用一把尺畫出一條線,讓紅點全在左邊、藍點全在右邊 = 線性可分。感知器的任務就是找出這條線的「斜率」和「位置」。這條線的兩個參數就是權重 w₁、w₂ 與偏權值 θ。

2. 手算一遍:感知器是怎麼「學」的

用講義的資料,輸入都補上一個固定的 −1 當偏權值的輸入,x=[−1, x₁, x₂]ᵀ、w=[θ, w₁, w₂]ᵀ,所以 u = wᵀx = −θ + w₁x₁ + w₂x₂。四筆資料:

kx₁x₂期望 d
1−0.5−0.5+1
2−0.5+0.5+1
3+0.3−0.5−1
4−0.1+1.0−1

設學習率 η=0.1,(舉例用)起始權重 w=[0, 1, 1]。第一輪(epoch 1):

  1. 樣本1 x=[−1,−0.5,−0.5]:u = 0 + (−0.5) + (−0.5) = −1 → y=−1;但 d=+1,分錯。d−y=2。w ← w + 0.1×2×x = [0,1,1]+[−0.2,−0.1,−0.1] = [−0.2, 0.9, 0.9]。
  2. 樣本2 x=[−1,−0.5,0.5]:u = 0.2 −0.45 +0.45 = 0.2 → y=+1 = d,對了,不更新。
  3. 樣本3 x=[−1,0.3,−0.5]:u = 0.2+0.27−0.45 = 0.02 → y=+1,但 d=−1,分錯。d−y=−2。w ← w + 0.1×(−2)×x = [−0.2,0.9,0.9]+[0.2,−0.06,0.1] = [0, 0.84, 1.0]。
  4. 樣本4 x=[−1,−0.1,1.0]:u = 0 −0.084 +1.0 = 0.916 → y=+1,d=−1,分錯。w ← [0,0.84,1.0]+(−0.2)×[−1,−0.1,1.0] = [0.2, 0.86, 0.8]。

第二輪再從樣本1開始檢查(此時 u=−1.03,仍分錯,繼續修正)…一直重複,直到某一輪四筆全對,就停止。資料線性可分 → 保證會停。

直覺分錯的樣本 x 會把 w「拉向」(或推離)自己,讓下次判斷它時更可能對。這就是「誤差修正學習」。

3. 收斂定理的證明,白話版

把權重向量想成一個箭頭 w。每次更新只發生在「分錯」的時候。

  • 每次更新都讓 w 更靠近「正確答案」w₀ 的方向 → 兩者的內積至少增加 α。n 次更新後內積至少 nα,所以 ‖w‖ 至少要有 nα/‖w₀‖,平方後是 n² 級別的下界。
  • 另一方面,每次更新時 ‖w‖² 最多增加 β(因為分錯的樣本讓交叉項為負,不會增加),所以 n 次更新後 ‖w‖² 最多 nβ,是 n 級別的上界。
  • n² 成長的下界 ≤ n 成長的上界 → 只有 n 不大時才成立 → n 有天花板 = 更新次數有限 = 收斂。
考試重點① 為什麼收斂(下界 n²、上界 n)② 初始權重非 0 也保證收斂 ③ 需「線性可分」前提。

4. 邊界方程式怎麼來的

兩個輸入時,決策邊界是 w₁x₁ + w₂x₂ − θ = 0。解 x₂:x₂ = −(w₁/w₂)x₁ + θ/w₂,這就是斜率為 −w₁/w₂、截距為 θ/w₂ 的直線。 θ 越大,線平移越遠;w 的比例決定線的傾斜度。

逐筆(誤差修正)批次(代價函數)

6. 常見疑問

Q:sign 函數在 u=0 時輸出什麼?不同教材規定不同;講義在 Hopfield 時規定「u=0 時保留原值」。實作時遇到 u=0 要先約定好規則,否則可能無法判定。
Q:為什麼感知器解不了 XOR?XOR 的四個點(0,0)(1,1)為一類,(0,1)(1,0)為另一類,對角線相同類別,無法用一條直線隔開。需要兩個神經元畫兩條線(隱藏層)再組合,見第 6 講。
Q:η 要設多少?範圍 0<η≤1。講義實驗用 10⁻¹ 到 10⁻⁶。新手可先用 0.1,不收斂再縮小。
